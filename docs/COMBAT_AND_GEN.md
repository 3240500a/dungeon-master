# COMBAT_AND_GEN.md — боевые формулы, монстры, генерация (дизайн-док)

Согласованный план доработок. Реализация по порядку: A → B → D → C.

## A. Единые боевые формулы (все статы работают)
- **DamagePacket** `{ physical, fire, cold, lightning, poison }` (4 стихии).
- **База оружия несёт свой тип урона** (`damageType` на базе предмета): меч/лук → physical,
  посох → fire/cold/… `weaponType` (melee/ranged/magic) отдельно — паттерн атаки + скейл
  от атрибута (Сила/Ловкость/Интеллект). Стихийные добавки `add-<стихия>` с гира/скиллов
  стекаются поверх базы.
- **`resolveAttack(attacker, defender, packet, rng) → {hit, blocked, crit, byType, total}`**
  (чистая, `shared/formulas/combat.ts`, с тестами). Порядок:
  1. Попадание: `hitChance = clamp(acc/(acc+evade), 0.05, 0.95)`; промах = 0.
  2. Блок (как D2 — полное гашение): `blockChance` (кап 75%).
  3. Крит: `critChance` → пакет × `critMultiplier`.
  4. Снижение: физ. `armor/(armor + 30 + 5×lvlАтакующего)`; стихии `×(1−clamp(res,−0.75,0.75))` (кап 75%).
  5. Сумма. Симметрично игрок↔монстр.
- **Меткость (accuracy, рейтинг)** = `20 + Ловкость×2 + бонусы`. **Уклонение (evade, новый)** =
  `10 + Ловкость×1.5 + бонусы`.
- **CombatStats** — единый блок для игрока и монстра (maxHp, min/maxDamage, damageAdd,
  attackSpeed, accuracy, evade, armor, blockChance, crit, critMult, res*, level).
  Пакет урона строится отдельно от статов (`buildPacket`).

## Оружие / щит / двуручки / дуал-вилд
- Слоты: `weapon` (осн. рука) + новый **`offhand`** (щит ИЛИ второе 1-ручное оружие).
- Базы: `hands` (1/2), `block` (оружие — мало, щит — много), `damageType`.
- Правила: двуручка → offhand пуст; одноручка → offhand щит или 1-ручное.
- **Блок = только weapon.block + offhand(shield).block**, кап 75% (пассивки/прочий гир не влияют).
- **Дуал-вилд:** удары **по очереди** (левая/правая), каждая рука — свой урон и тип;
  небольшой бонус к скорости атаки. Двуручка — крупнее база, без offhand.

## B. Монстры: стат-блок + генератор
- Расширить `MonsterDef` до боевого блока (урон min–max + тип, armor, accuracy, evade,
  blockChance, crit, 4 сопротивления, attackSpeed, xp, восприятие).
- `monsterStats(def, depth, affixes, rarity)` → CombatStats.
- **Генератор:** база из пула темы + масштаб по глубине + **малый пул аффиксов**
  (огненный/быстрый/бронированный/живучий/меткий, 0–2) + **редкость обычный/чемпион**
  (крупнее, +аффиксы, +xp/лут). Конфиги: `monsters.json` (расшир.), `monster-affixes.json`.

## C. Подземелья — 3 прохода (+ двери/ключи + туман войны)
1. **Схема:** вход → комнаты (короткие коридоры) → выход. Типы: малая/большая/сокровищница/
   босс(выход)/вход. Раскладка сетка/BSP + MST + петли, гарантия пути. **Дверь+ключ** на пути
   к выходу/сокровищнице.
2. **Реализация комнаты:** тайлы по стилю типа (прямоуг./колонны/неровная), декор (колонны,
   обломки, факелы, сундук, арена), коридоры. Стили/декор в конфиге по типу.
3. **Пачки монстров** (`packs.json`, редактируемы/генерируемы): состав + вес; спавн по комнатам,
   **формация — рандом в небольшом радиусе**; босс-комната → босс-пачка; монстры из генератора B.
- **Туман войны:** потайловая видимость через `world/lineOfSight` (видно/исследовано/тьма).
- На будущее: типы «пещеры»/«склеп-лабиринт», больше дверей/секретов.

## D. Боевая система — интеграция
- Оба направления урона через `resolveAttack`.
- Поведения способностей (`abilityId → эффект`): рассечение=конус, нова=кольцо, мультивыстрел=веер,
  метеор=точечный удар, аура/клич=баф; каждый несёт свой пакет (стихия по ветке).
- Фидбэк: всплывающие числа цветом по типу, «промах»/«блок», крит крупнее, **КД на хотбаре**.
- Снаряды через `resolveAttack`, снаряды монстров-стрелков; опц. пронзание.

## Конфиги/схемы
- `items.base`: `damageType`, `hands`, `block`; слот `offhand`; аффиксы `add-<стихия>`.
- `monsters.json` (расшир.) + `monster-affixes.json`.
- `dungeons.json`: layout-алгоритм, микс комнат, стиль декора, пул пачек, дверь/ключ, модификаторы; `packs.json`.
- `balance`: константы формул (armor K, hit clamp, block cap, крит, масштаб глубины, радиус тумана).
