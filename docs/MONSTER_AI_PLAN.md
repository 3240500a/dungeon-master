# Монстры: аудит + план доработок (ориентир D2 / PoE2)

Аудит текущей системы (server-authoritative sim, `packages/shared/src/session`) и план улучшений
по ИИ/патфайндингу/поведению/элиткам. Цель: монстры ведут себя адекватно, не стреляют сквозь
стену, обходят препятствия, а чемпионы/рары дают глубину как в D2/PoE2.

## 1. Аудит: как работает сейчас

### Восприятие / агро (`ai.ts:26-47`)
- **Зрение** = дистанция + конус (`visionAngle/2`) + **LoS** (`hasLos`, Bresenham). Корректно.
- **Слух** = чистый радиус × громкость брони (`noiseMult`), **без конуса и без LoS** → слышит сквозь стены.
- **Шум**: любая базовая атака игрока = шум радиус 220 (`session.ts:427`) → будит всех в радиусе сквозь стены (`alertTimer=2.5с`). Получение удара форсит агро.
- **Деагро/leash** (`ai.ts:42-45`): chase→idle через `LEASH_TIME=3.5с` без контакта ИЛИ дист>560. **Нет возврата на спавн, нет сброса HP, нет анкора дома.**
- **Цель** = ближайший игрок по сырой дистанции каждый тик (`session.ts:320`) → дёргается между целями, игнорит LoS/стены.

### Состояния (`state.ts:92`)
- Всего **два**: `idle | chase`. Нет flee/return/patrol/wander. Idle = стоять + медленно крутить фейсинг (скан конуса, `ai.ts:70-75`). Stun/windup — отдельные под-состояния.

### Бой (`ai.ts:85-122`)
- **melee-chaser**: прямая радиальная линия на цель, стоп на `radius+18`, атака. Без обхода, без стрейфа.
- **ranged-kiter**: радиальный кайт (назад <140, вперёд >220, держать 140–220), выстрел если `dist<260`. Без стрейфа, пятится **в стены/углы**.
- **stationary**: не движется.
- **Замах/телеграф** (`session.ts:346-353`): рутован, смотрит на цель, событие `monster-swing`. Мили **перепроверяет дистанцию** после замаха (может промазать по ушедшему). **Выстрел бьёт безусловно** — без LoS и без реролла дистанции.

### Патфайндинг / движение / снаряды
- **Патфайндинга у монстров НЕТ.** BFS `findPath` (`world/pathfind.ts`) **существует**, но используется только ботом-игроком (`bot.ts`). Монстры рулят прямо на игрока → **застревают в углах**, упираются в стену (только скольжение по независимым осям, `movement.ts`).
- **Дальняя атака без LoS-гейта** (`ai.ts:100-103`): решение стрелять — только по дистанции. `hasLos` считается каждый тик и **не подключён** к гейту стрельбы. Снаряд гаснет о первую стену (`session.ts:1079`), но монстр «палит вслепую» (в т.ч. агро по слуху сквозь стену); диагональные щели Bresenham могут пропустить болт за угол.
- **Коллизии**: масс-взвешенная мягкая сепарация пост-проходом (`separation.ts`), клампинг о стены. Чемпионы тяжелее (расталкивают).

### Генерация / чемпионы / рары (`monstergen.ts`, `floor.ts`)
- 3 базовых монстра (skeleton, zombie, skeleton-archer). Стат-блок богатый (hp/урон/армор/резисты/vision/скорости/крит…).
- Скейл по глубине (challenge level): hp ×(1+d·0.8), урон ×(1+d·0.3), плоские добавки армор/резист. **Скорости и critMult не скейлятся** намеренно.
- **Чемпион — единственный элит-тип**: 8% или форс (champion/boss-комната), ×2.5 HP, ×1.5 урон, ×3 xp, +реген, +2 аффикса. Под-типов нет, именованных боссов нет.
- **Рарных/уник-монстров как тира НЕТ.** «Elite» — свойство этажа (больше champion-комнат).
- **Аффиксы монстров** — 6 чисто-числовых (`monster-affixes.json`: fiery/icy/swift/armored/vigorous/accurate), `{mult, add, damageType}`. **Нет весов/тиров/гейтов/групп** (в отличие от предметных аффиксов) и **нет поведенческих/аура-модов**.
- **Пачки**: по `roomType`→роли→монстр из пула биома, случайная клетка. Без лидеров/миньонов/анкоров.

## 2. Референс D2 / PoE2 (кратко)
- **D2**: тиры normal → **champion** (пачка 4–5, под-типы Berserker/Fanatic/Ghostly/Possessed, +HP) → **unique** (1 на группу + миньоны, ×4 HP, 1–2 случайных **поведенческих** мода: Extra Fast, Cursed, Fire/Cold/Lightning Enchanted (новы на смерти), Multiple Shots, Stone Skin, Aura Enchanted, Teleport, Mana Burn…). Есть патфайндинг с обходом стен; дальние/касты требуют LoS.
- **PoE2 (Archnemesis)**: magic-пачка делит **1** мод, rare несёт **2+**. Категории: Speed / Damage / Defence / Environmental hazards (земля-эффекты, мортиры) / Curses / Minions / Auras — каждый мод «читаемый» в бою.
- **Вывод**: элитки = **база + набор модификаторов** (ложится на нашу схему как аффиксы на предметы) + адекватный патфайндинг + LoS-гейт на дальние.

## 3. Концепция: настраиваемые профили поведения по фракциям

Два слоя, разделяем:
- **`ai` (как атакует)** — на монстре: `melee | ranged | stationary` (остаётся).
- **Профиль поведения (как ведёт себя)** — **новый конфиг по фракциям** (`monster-behaviors.json`),
  редактируется в HTML-редакторе. Монстр берёт профиль по своей `faction` (позже — опц. override на
  конкретного монстра). Один общий расширенный FSM (`idle · investigate · chase · attack · reposition ·
  flee · regroup · return`), профиль включает/тюнит нужные ветки (data-driven FSM + веса «личности»).

**Инвариант ростера:** каждая фракция — **mostly-melee**: 70–90% мили, 10–30% дальний. Мили несёт
характер фракции; дальний — акцент-меньшинство. Все «дальние» — одна роль `ranged`, но ведут себя
по-разному (лучник-отскок ≠ блинк-каст ≠ турель).

**Биом = забег.** Биом привязан к фракции (`biomes[].faction`, schemas.ts:926). Забег по биому =
полный ростер этой фракции (2–3 мили-архетипа + 1 дальний + чемпион), пачки 70–90% мили. «Полноценность»
даётся через РОЛИ (натиск/фланг/дальний/танк-элита), «специфика» — через профиль фракции.

### 3.1 Принцип: одинаковое ядро, небольшие отличия

Ядро геймплея во всех биомах одинаково — **мясить толпы мобов**. Фракции дают **небольшие** отличия
в поведении (в основном порог отхода + пара акцентов), а не радикально разные архетипы. Мили — почти
одна база «идёт и бьёт», отличается **осторожностью**; в дальнем бою различия заметнее.

| Фракция | Тема | Мили — 70–90% (мелкие отличия) | Дальний — 10–30% |
|---|---|---|---|
| **Нежить** | скелеты/зомби | тупо вперёд, **не отступает** (самое простое) | лучники: выстрел + отскок |
| **Звери** | волки/хищники | вперёд, **отступают при низком HP** (~18%), потом снова в бой; чуть быстрее/стайнее | плевуны: короткий кайт |
| **Демоны (джинны)** | ифриты/песок/магия | вперёд, но **осторожны/трусоваты** — отступают раньше/чаще (~35%), держат чуть дистанцию | колдуны: **блинк-касты** стихии |
| **Монстры (конструкты)** | големы/магомеханизмы | **бесстрашны** (не отступают), «ИИ на победу» — оптимальный фокус/подход, без тупняка; базовые обычные, **БОЛЬШИЕ — медленные тяжёлые телеграф-удары** | стражи-турели: луч/залп |

Главный per-faction рычаг мили — **порог отхода `fleeHpPct`**: нежить 0 (fearless-тупой) · звери ~18% ·
демоны ~35% (трусоваты) · конструкты 0 (fearless-умный). Отдельный акцент — только у БОЛЬШИХ
конструктов (тяжёлый телеграф) и в дальнем бою (отскок / кайт / блинк-каст / турель).

### 3.2 Открытые выборы (обсуждаются)

- **Конструкты, сигнатура на смерти:** overload-взрыв (рек.) · self-repair/щит · распад на мини-конструкты.
- **«Большие» конструкты:** по какому признаку (радиус/тег базы) считать большими для тяжёлого телеграфа — уточнить в контенте (Ф5).

## 4. Параметры профиля (редактор, на фракцию)
- **Агро:** `alertDelaySec` (задержка «заметил»), `hearingMode` (`chase` | `investigate`), `leashTimeSec`,
  `leashRadius`, `returnHome`.
- **Движение/бой:** `engageStyle` (`advance` | `juggernaut`), `fleeHpPct` (0 = fearless — **главный
  per-faction рычаг мили**), `keepDist` (min/max для дальних), `repositionMode` (`strafe` | `blink` |
  `none`), `repositionAfterShot`, `packCohesion` (звери), `aggression`, `heavyTelegraph` + `poise`
  (большие конструкты), `signature` (`none` | `blink-cast` | `overload` | `sentry`).

## 5. Фазы реализации (A + B встроены)
- **Ф1 — Схема профилей + резолвер (shared):** `monster-behaviors.json` + `monsterBehaviorSchema` (4 фракции),
  `behaviorFor(m)`; дефолты 4 фракций по таблице 3.1.
- **Ф2 — Блок A (адекватность):** LoS-гейт на `shoot`/`attack` (перепроверка после замаха); `alertDelay`;
  слух → `investigate` (или сразу `chase` у тупых). Убирает «стрельбу сквозь стену».
- **Ф3 — Блок B (патфайндинг, гибрид):** прямой ход при `losClear`, иначе `findPath` (уже есть в
  `world/pathfind.ts`); отход/кайт в **открытую** сторону. Универсально для всех фракций.
- **Ф4 — FSM по профилям:** мили-феел (swarm / flank-hit&run / blink-strike / juggernaut) + дальний-феел
  (reposition / kite / blink-cast / sentry); flee/fearless; heavy-telegraph.
- **Ф4b — Сигнатуры (движковые способности):** телепорт джиннов (в т.ч. блинк-удар мили) + overload
  конструктов. Пересекается с блоком E (поведенческие аффиксы).
- **Ф5 — Контент + баланс:** per-faction ростер (мили-мажор + дальний-минор), веса пачек 70–90% мили,
  биом→фракция; редактор. Сейчас монстров всего 3 (все нежить) — нужен ростер по каждой фракции.
- **Ф6 — Тесты + verify:** не стреляют сквозь стену; обход стены; ratio мили/дальний; flee при low-HP;
  резолвер по фракции; typecheck/vitest/build.
