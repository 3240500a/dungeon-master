# SKILLS_DESIGN.md — переработка активных скиллов (дизайн)

> **АКТУАЛЬНО (Ф1–Ф7):** классового деления активок больше нет. Все скиллы — в ЕДИНОМ радиальном
> древе `skill-tree` (актив+пассив по 32 веткам: 1руч/2руч/дальнобой/дуал/жезл-посох, стихии,
> проклятья, ауры, стойки, броня×3, щит + сигнатурная ветка класса). Боевые активки тратят
> **выносливость**, магические — **ману**. Прокачка за очки скилла по смежности, сброс за золото
> (`respecSkills`). Общие %-пассивы вынесены в отдельное **дерево мастерства** (`mastery-tree`, за
> золото). Разделы ниже — исходный дизайн-словарь механик (attack/cast/curse/aura/stance/buff, замах,
> стих. статусы), он актуален; привязка «ветка = класс» устарела. Числа — под калибровку (Ф7).

Цель: сделать ветки специализированными и «своими» для каждого класса. Сейчас все
активки — это перекрашенная нова или веер из 3 снарядов (движок читает только
`abilityId` → стихия по имени + AoE-или-снаряд). Нужен **словарь механик** + контент.

**Принципы:** ветка = стиль/оружие/стихия. В каждом классе — микс: замены-атаки,
нюки по КД, тоглы/стойки/ауры, баффы, проклятия, ловушки, мобильность, (призывы),
и **мастерства** (пассивы внутри ветки, усиливают именно её урон/стихию — синергия).

## Категории активок (v3 — реализовано, дискриминатор `category`)
| Тип | Тайминг | Общий attack-лок | Урон | Роль |
|---|---|---|---|---|
| **attack** | скорость атаки × `speed` + замах | **да** | **от оружия** ×`damageMult`; мили ИЛИ веер снарядов (`count`/`spread`/`pierce`) | основной спамовый урон всех классов (воин/лучник/маг) |
| **cast** | `castTimeSec` / `castSpeed`(Инт) + личный `cooldown` | нет | от оружия ×`damageMult` + конверсия `convertPct` в стихию каста | особая механика `shape`: `dash`/`leap`/`nova`/`ground`/`meteor`/`boomerang` |
| **curse** | как cast (castSpeed) | нет | — (дебаф) | `ailment`/`taunt` врагам в `radius` |
| **buff** | мгновенно, `durationSec` (рефреш) | нет | — | временное усиление себе (`buffMods`) |
| **aura** | тогл, резерв `reservePct` | нет | — | бонусы себе+пати в радиусе |
| **stance** | тогл, резерв, эксклюзив `toggleGroup` | нет | — | бонусы только себе |

**Модель стихий:** `attack` бьёт стихией ОРУЖИЯ (посох огня → огонь), `element` скилла — только статус/цвет.
`cast` конвертит долю урона оружия в свою `element` (+добавка) — для огне-билда бери огненный посох, чтобы
пассивки на огонь применялись и к нему. **Скорость каста** `castSpeed` растёт от Интеллекта (+гир `castSpeed`).

## Наши системы — как всё работает (свериться перед дизайном скиллов)
*Проверено по коду. Скиллы/мастерства меняют это модификаторами `StatModifier` (`flat`/`increased`).*

**Статы (`DerivedStats`):** maxHp, maxMana, minDamage/maxDamage, attackSpeed, critChance,
critMultiplier, armor, moveSpeed, accuracy, evade, blockChance, addFire/addCold/addLightning/
addPoison (плоская стих. добавка), hpRegen, manaRegen, resFire/resCold/resLightning/resPoison
(−0.75..0.75). → +% к любому из них = существующая механика, «бесплатно».

**Бой (`resolveAttack`), порядок:** попадание `acc/(acc+evade)` кламп 5–95% → **блок** (полное
гашение, `blockChance` 0–75%, только от оружия/щита) → **крит** (`critChance` × `critMultiplier`)
→ снижение: физ. бронёй `armor/(armor+30+5×ур.атакующего)`, стихии — сопротивлениями (кап 75%).

**Дебаффы (8: 4 физ. по подтипу оружия + 4 стих. по типу урона; стаки+таймер+магнитуда):**
| Дебафф | От | Эффект на цель |
|---|---|---|
| Рана (`wound`) | колющее | −её урон, −её скорость |
| Кровотечение (`bleed`) | режущее | DoT + −её меткость |
| Увечье (`sunder`) | рубящее | +получаемый урон, −реген вдвое |
| Ошеломление (`daze`) | дробящее | −её броня, −скор.атаки, копит **шанс оглушения** |
| Поджиг (`burn`) | огонь | DoT (огонь) |
| Отравление (`poison`) | яд | DoT (яд) |
| Шок (`shock`) | молния | +получаемый урон |
| Заморозка (`freeze`) | холод | −скорость/−скор.атаки, копит **шанс сковать** |
Физические держатся **выдержкой** брони (`armorPoise`, кап 60%), стихийные — стихийными
**сопротивлениями**. `ELEMENT_AILMENT` = fire→burn, cold→freeze, lightning→shock, poison→poison.

**Оружие (оси, `docs/WEAPONS.md`):** вес (сверхлёгк./лёгк./средн./тяж. → множители Power/Finesse
+ скейл от Силы/Ловкости), подтип (колющее→рана, режущее→кровот., рубящее→увечье, дробящее→
ошеломл.), класс (меч/топор/булава/кинжал/копьё), руки (2H даёт ×1.3 к силовым). Сигнатуры
предмета: `stunChance`, `armorPenPct`, `arcMult` (дуга удара), `reachMult` (досягаемость),
`lowHpBonusPct` (добивание), `knockback` (отброс).

**Броня (5 классов, `docs/ARMOR.md`):** стёганая/кожаная/кольчужная/сегментная/латная. Даёт
штрафы move/atk/evade + шум (для слуха монстров) + выдержку (poise) по видам дебаффов. Латная —
макс. броня/штрафы/шум, лучшая выдержка vs ошеломление.

**Способности (текущий движок):** урон = базовый удар оружием × mult × `abilityRankMult`
(+12%/ранг). Стихия и AoE-vs-снаряд определяются по имени `abilityId` (это и расширяем — см. ниже).
Блок/стан/отброс — уже есть; heal/скилл-скорость/тоглы/сет-бонус/аффинити — новое.

## Словарь механик (движок) + стоимость реализации
`active.type` (новое поле) → как считать способность:
| type | что делает | стоимость |
|---|---|---|
| `cleave` | мили-дуга AoE (как база, но скилл) | **дёшево** (есть meleeSwing) |
| `projectile` | 1..N снарядов; параметры: count/spread/pierce/speed | **дёшево** (есть веер) |
| `nova` | мгновенный AoE вокруг игрока | **дёшево** (есть) |
| `strike` | одиночный мощный удар (×mult), сильный дебафф | средне |
| `multi-strike` | N быстрых ударов по цели/конусу | средне |
| `meteor` | отложенный AoE в точке цели | средне |
| `ground` | зона на земле: DoT/замедление на время | средне |
| `chain` | снаряд прыгает между ближними врагами | средне |
| `dash` | рывок по направлению (+урон/стан/отброс) | средне |
| `buff` | врем. бафф статов себе/области на КД | средне |
| `curse` | дебафф врагам в области (−броня/−урон/страх) — движок дебаффов уже есть | средне |
| `toggle` | стойка/аура: держит стат-моды пока включена; **эксклюзивные группы** (одна за раз); резерв маны | крупнее |
| `channel` | вихрь/метель: урон/тик пока удерживаешь, тратит ману/тик | крупнее |
| `trap` | ставит ловушку, срабатывает от врага рядом (урон+корень) | крупнее (сущность+триггер) |
| `summon` | призыв союзной сущности с ИИ | **большая система** |

**Статусы стихий** (расширить движок дебаффов, как физ-подтипы): `burn` (огонь-DoT),
`chill` (замедление), `freeze` (кратко обездвиж.), `shock` (+получаемый урон). Привязка:
огонь→burn, лёд→chill/freeze, молния→shock, яд→poison-DoT.

**Мастерства:** новый стат-мод «+% урон стихии X» / «+% урон оружием» — усиливает пакет
урона ветки (сейчас есть только плоские addFire и т.п.).

## Реализация — по фазам (от дешёвого к дорогому)
1. **Каркас механик:** поле `active.type` + параметры; движок `executeAbility` по типам.
   Сразу закрывает: cleave/projectile(+pierce/count)/nova/strike/multi-strike/meteor/ground/chain/dash.
2. **Тоглы/стойки/ауры + баффы:** эксклюзивные группы, стат-моды на время/пока-вкл; резерв маны.
3. **Статусы стихий:** burn/chill/freeze/shock в движке дебаффов + мастерства «+% урон стихии».
4. **Ловушки/каналы:** trap-сущности, channel-удержание.
5. **Призывы (некромант):** союзные сущности с ИИ — отдельный майлстоун (переиспользует ИИ монстров).
6. **Контент-джен:** пересобрать `skills-active.json` под ветки выше (мастерства+ранги наполняют дерево),
   переписать генератор `skills-active/*` и цены/levelReq. Обновить сим-бота (использует активки по type).
