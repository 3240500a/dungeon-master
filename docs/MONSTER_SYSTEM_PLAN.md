# Монстры: система атрибутов + экипировки + ростер (план)

Унификация: **монстр = атрибуты (STR/DEX/INT/VIT) + экипировка**, статы деривятся тем же матом, что
у игрока. «Афиксы монстра» = афиксы на его сгенерированном гире. Дополняет `docs/MONSTER_AI_PLAN.md`
(поведение по фракциям — уже сделано).

## 1. Принцип

- **Авторинг монстра:** `{ id, name, faction, subfaction?, role, tier, attrs:{str,dex,int,vit},
  weapon, armor?, offhand?, ai?, vision/visionAngle/hearing, moveSpeed?, sprite }`. Боевые статы НЕ
  задаются вручную — деривятся.
- **Рантайм (`ScaledMonster`)** — прежняя плоская форма (hp/minDamage/maxDamage/armor/acc/evade/crit/
  resists/attackSpeed/damageType/level/xp/…). Движок читает её без изменений; меняется только генератор.
- **Деривация (переиспользует `deriveStats` игрока):**
  - **VIT** → HP (+реген), **STR** → мили-урон + армор + вес, **DEX** → меткость/уворот/скор.атаки/крит
    + дальний-урон, **INT** → маг-урон + скор.каста.
  - **Урон = урон оружия × скейл по атрибуту** (STR/DEX/INT-доли по весу оружия — тот же
    `weaponAttrScaling`), **защита = из брони**, **AI и тип урона — из оружия** (мили/дальний/кастер).
  - **Уровень** растит атрибуты per-level → всё деривнутое масштабируется. Глубина = уровень монстра.

## 2. Монстро-гир (отдельная библиотека по фракциям)

Новый конфиг **`monster-gear`** — те же параметры, что у `items.base` (оружие: урон/вес/тип урона/хват/
attackType; броня: класс/защита/требования), но отдельный пул, тегированный `faction` (+ подфракция).
- Нежить — кованое/костяное (мечи/топоры/булавы/луки/арбалеты/посохи + Стёганая/Кожаная/Кольчуга/
  Сегментная/Латная + щиты).
- Звери — природное (когти/клыки/плевок как «оружие» + шкура-«броня»); конструкты — встроенное
  (кулаки/молоты/лучи); джинны — магия (ятаганы/посохи/болты). (пулы зверей/конструктов/джиннов — позже.)

Монстр ссылается на гир по id: `weapon` (обяз.), `armor?`, `offhand?` (щит). Метательный топор = `axe`
с `attackType: ranged`.

## 3. Афиксы монстров = афиксы на гире (унификация с item-движком)

Вместо `monster-affixes.json` (стат-мульты, депрекейт) — генератор **одевает монстра гиром через тот
же `rollAffixes`**:
- редкость монстра → редкость гира: normal (0 афиксов) · magic (1–2) · champion/rare (3+);
- **подфракция задаёт тему афиксов** через `tagWeights` (культ огня → огненные чаще — механизм уже есть);
- стат монстра = деривация(**атрибуты + гир с афиксами**). Гир может дропаться (по желанию).

## 4. Подфракции (визуал + тема афиксов)

Каждая фракция → подфракции: чисто визуальный скин + тема афиксов для magic/rare. Забег = одна
подфракция. Для нежити: Культ огня (fire) · Культ стужи (cold) · Культ тлена (яд/некро) · Культ грозы
(lightning) · базовый (физ/некро). Конфиг подфракций (визуал/тема) — редактируемый.

## 6. Фазы
- **Ф1 — Схемы:** новый `monstersSchema` (атрибуты + гир + role/tier/subfaction + перцепция); конфиг
  `monster-gear` (faction + оружие/броня как `items.base`); конфиг `subfactions`. `ScaledMonster` рантайм — как есть.
- **Ф2 — Деривация:** `deriveMonsterStats(def, gear, level, scaling)` → `ScaledMonster` (переиспользует
  `deriveStats` + урон оружия×атрибут + защита брони; AI/тип урона из оружия).
- **Ф3 — Генератор:** `generateMonster` резолвит гир, деривит на уровне, катает гир-афиксы по редкости +
  тема подфракции, применяет к статам. `monster-affixes` депрекейт.
- **Ф4 — Контент:** андед-`monster-gear` (оружие/броня, костяное/ржавое) + 13 типов (атрибуты/роль/тир/гир) +
  подфракции; веса пачек 70–90% мили.
- **Ф5 — Редактор:** ВСЁ по монстрам настраиваемое — атрибуты/гир/роль/тир/подфракция, вкладки
  `monster-gear` и `subfactions`, **live-превью деривнутых статов** (как генератор предметов).
- **Ф6 — Тесты + verify + доки** (деривация, скейл по уровню, гир-афиксы по редкости/подфракции, ростер).
- **(позже)** пулы гира зверей/конструктов/джиннов; шаман-heal/buff; главарь-аура (блоки D/E).
