# ARMOR.md — система брони (дизайн)

По аналогии с оружием: у брони есть **класс** (материал), задающий защиту, штрафы за
подвижность, профиль выдержки и шум. Data-driven; тиры (`item-tiers.json`) масштабируют броню.

**5 классов по возрастанию** (id / рус.): `quilted`/Стеганая · `leather`/Кожаная ·
`chain`/Кольчужная · `segmented`/Сегментная · `plate`/Латная.

---

## Ось 1 — Класс брони (5 ступеней)
Значения — **вклад одной части**; суммируются по надетым частям (штрафы капятся).
| Класс | Броня ×база | −Бег/часть | −Скор.атаки/часть | Уворот/часть | Треб. |
|---|---|---|---|---|---|
| **Стеганая** | ×0.5 | 0% | 0% | +2% | — (нет) |
| **Кожаная** | ×0.75 | 0% | 0% | **+4%** | Ловкость |
| **Кольчужная** | ×1.1 | −1.5% | −1% | 0 | Ловк > Сила |
| **Сегментная** | ×1.6 | −3% | −2.5% | −3% | Сила > Ловк |
| **Латная** | ×2.3 | −4.5% | −3.5% | −6% | Сила |

- Слоты с классом: шлем, нагрудник, перчатки, сапоги, пояс, щит (offhand).
- **Капы:** суммарный штраф бега ≤ −45%, скор. атаки ≤ −40%, уворот не ниже 0.
- **Скейл:** броня — flat (база × класс × тир); уворот растёт от Ловкости. → стеганая/кожаная +
  Ловкость = уклонение (маг/ловкач); латная + Сила = танк.

### Требования по классу (×reqMult тира). Переход Ловкость → Сила с ростом класса.
| Класс | Нагрудник / щит | Мелкие слоты (×0.5) |
|---|---|---|
| Стеганая | — | — |
| Кожаная | Ловк 12 | Ловк 6 |
| Кольчужная | Ловк 14 + Сил 8 | Ловк 7 + Сил 4 |
| Сегментная | Сил 16 + Ловк 8 | Сил 8 + Ловк 4 |
| Латная | Сил 26 | Сил 13 |

### Броня по классу (тир-1; пример нагрудника, база ×1.0 = 12)
| Стеганая | Кожаная | Кольчужная | Сегментная | Латная |
|---|---|---|---|---|
| 6 | 9 | 13 | 19 | 28 |

**Ниши:** стеганая — «ткань» мага (нет треб., +уворот, но мало брони); кожаная — ловкач/лучник;
латная — ходячая крепость; кольчужная/сегментная — переход dex↔str.

## Механика 2 — Выдержка (профиль по типам дебаффа)
Каждый класс **лучше держит свой** тип дебаффа (стан/рана/кровот./ошеломл.), но тяжёлые
классы прочнее в целом (сумма растёт). Значение — выдержка/часть; снижает **шанс И
длительность** этого дебаффа. Сумма по частям, **кап 60% на тип**.

| Класс | Рана (колющий) | Кровотечение (режущий) | Увечье (рубящий) | Ошеломление (дробящий) |
|---|---|---|---|---|
| Стеганая | 1.5% | 1.5% | 1.5% | 1.5% |
| **Кожаная** | **6%** | 2% | 2% | 2% |
| **Кольчужная** | 3% | **7%** | 3% | 3% |
| **Сегментная** | 4% | 4% | **8%** | 4% |
| **Латная** | 5% | 5% | 5% | **9%** |

- **Специализация:** по своему дебаффу класс — лучший (кожаная от раны 6% > латной 5% и т.д.).
- **Общая прочность:** сумма по строке растёт (стеганая 6 → латная 24), т.е. латная всё равно
  защищённее лёгкой по совокупности.
- Полный комплект (×6): напр. латная от ошеломления 54%, кожаная от раны 36%.

## Механика 3 — Шум (стелс через слух монстров)
Громкость = 1 + Σ(частей); множит радиус `hearing`, с которого монстр слышит игрока.
Кламп [0.6, 1.8].
| Класс | Шум/часть | Полный комплект (×6) |
|---|---|---|
| Стеганая | −0.05 | ×0.7 (тихий подход) |
| Кожаная | −0.04 | ×0.76 |
| Кольчужная | +0.02 | ×1.12 |
| Сегментная | +0.07 | ×1.42 |
| Латная | +0.11 | ×1.66 (слышат заранее) |

## Модель данных (база брони)
```json
{ "id": "plate-armor", "name": "Латный доспех", "slot": "chest",
  "armorClass": "plate", "itemLevel": 6 }
```
Броня/штрафы/требования/выдержка/шум — из таблиц (перебиваются руками).

## Новые механики движка (когда закодим)
1. Класс брони → броня + штрафы бега/атаки/уворота (сумма + капы) в производных статах.
2. Требования брони по классу (гейт экипа, переход Ловк→Сила).
3. Выдержка (профиль по типам) → снижение шанса/длительности конкретного дебаффа (кап 60%/тип).
4. Шум → множитель радиуса `hearing` монстров.
5. Тултип: класс + броня + штрафы + выдержка-профиль + шум.
