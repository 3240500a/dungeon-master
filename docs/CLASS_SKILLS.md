# CLASS_SKILLS.md — детальные деревья активок по классам

Формат-эталон. Тип — из словаря механик ([SKILLS_DESIGN.md](SKILLS_DESIGN.md)). «Ярус» =
`levelReq`. Урон — множитель к базовому удару оружием. Числа стартовые, под калибровку.
*Курсив* = пассив/мастерство.

## Ключевая боевая модель (решено)
- **КД у активок НЕТ.** Скорость применения удара-скилла = **скорость атаки × коэффициент
  скилла** (`speed`): слабый бьёт быстрее (`×1.2–1.4`), мощный медленнее (`×0.5–0.7`).
- Не-атаки (зоны/метеор/провокация/лечение) — **без КД, ограничены маной** (и реген маны).
- **Тоглы** (стойки/ауры) — вкл/выкл, **резерв маны**; эксклюзивные группы (1 стойка + 1 аура).
- **Замах и прерывание:** тяжёлые (медленные) удары имеют короткий **замах** перед попаданием.
  Если во время замаха тебя **оглушают/ошеломляют** — удар **сбивается** (прерывание, мана теряется).
  Стат **«стойкость к прерыванию»** снижает шанс сбить замах (пробивной танк не даёт себя остановить).
- Колонка «Мана · Скор.»: для ударов — стоимость + коэффициент скорости; для не-атак — мана;
  для тоглов — резерв.

## Заступник — тяжёлый святой рыцарь (Сила, латы, +нежить/демоны)
Медленный несокрушимый танк-крушитель. Мощные удары медленны, но дробят и оглушают; латы
дают гору брони с малыми штрафами; **священный огонь** испепеляет нежить (света в игре нет —
его «святость» это огонь). Блок — не его конёк (это к Вьюге), его защита = броня и латы.

### Билды
- **Молот-контролёр** (Оружие+Оплот): Оглушающий/Небесный молот + Стойкость + Полный доспех —
  медленный неубиваемый танк, всё оглушено.
- **Пламенный каратель** (Пламя+Оплот): Аура пламени + Кара огнём + поджиг — гроза нежити,
  DoT-урон + саппорт-аура (кооп), живучесть от лат.
- **Крушитель** (Оружие+Пламя): Пламенный/Праведный удар + Аура пламени + Пламя Ордена —
  максимум урона (физ+огонь), меньше брони.
