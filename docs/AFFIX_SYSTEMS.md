# Аффиксы: как в D2/PoE2 и как у нас

Справка по системам сочетания аффиксов (Diablo 2, Path of Exile 2) и решениям в нашем движке
(`packages/shared/src/config/schemas.ts` → `affixesSchema`, `formulas/itemgen.ts` → `rollAffixes`,
контент `config/data/affixes.json`).

## Две философии

- **Diablo 2 — аффиксы ДИСКРЕТНЫЕ.** Каждый шаг силы стата — отдельный аффикс (`of Life` +10 и
  `of the Whale` +100 — разные суффиксы одной группы, разный уровень). Предмет при дропе набирает
  аффиксы и не меняется. Имя рара — 2 случайных слова, **не связаны** с аффиксами.
- **Path of Exile 2 — аффиксы ПАРАМЕТРИЧЕСКИЕ.** Один мод (напр. «# к макс. жизни») имеет тиры
  T1…Tn — диапазоны, открываемые по уровню предмета. Система вокруг крафта, тегов и весов.

**Общие правила «сочетаемости»:** слоты префикс/суффикс с раздельными лимитами; взаимоисключение
групп (не больше одного аффикса из семьи); гейт по типу предмета; гейт по уровню; взвешенный
рандом; редкость задаёт количество.

## Таблица 1 — D2 vs PoE2

| Механика | Diablo 2 | Path of Exile 2 |
|---|---|---|
| Слоты | префикс / суффикс | префикс / суффикс |
| Кол-во на magic | 0–2 (25% преф / 50% суф / 25% оба) | до 2 (1 преф + 1 суф) |
| Кол-во на rare | 3–6 (≤3 преф + ≤3 суф) | до 6 (3 преф + 3 суф) |
| Взаимоисключение | группа/семья: 1 на группу | mod group: 1 на группу |
| Значения / тиры | каждый шаг — ОТДЕЛЬНЫЙ аффикс (одна группа, разный уровень) | ОДИН мод с тирами T1…Tn |
| Гейт по уровню | `ilvl(+qlvl,maglvl)→alvl` — какие аффиксы доступны | `ilvl` открывает верхние тиры |
| Частота | Frequency (вес) внутри пула | Weight, модулируется тегами базы |
| Гейт по типу | тип/класс предмета | теги базы + группы |
| Роли слотов | слабая конвенция | сильная: преф = урон/значения, суф = резисты/атрибуты/утилита |
| Имя рара | 2 случайных слова (косметика) | случайное имя, аффиксы отдельно |
| Крафт | почти нет | ядро игры (орбы/эссенции/теги) |

## Наша конвенция ролей слотов (PoE2)

Закреплена тестом (`itemgen.test.ts` → «роли слотов»):

- **Префикс** = «сила предмета»: чистый урон (`minDamage/maxDamage/physPct/damagePct`,
  `addFire/Cold/Lightning/Poison`), а также значения (жизнь/мана/броня/крит/скорость атаки).
- **Суффикс** = утилита/сопротивление/атрибуты: резисты (`res*`), атрибуты
  (`strength/dexterity/intelligence/vitality`), а также вампиризм/за-убийство/реген/блок/меткость.
- **Жёсткое правило (тест):** чистый урон → ТОЛЬКО префикс; резист/атрибут → ТОЛЬКО суффикс.
  «Значения» (жизнь/мана/броня/уворот/крит/скор.атк) допускаются в любом слоте.

## Веса по тегам базы (PoE2)

`affix.tagWeights: [{ tag, mult }]` — множитель к `weight`, если у базы есть токен `tag` (тот же
набор, что `appliesTo`: `weapon.magical`, `weapon.physical`, `armor`, слоты и т.п.). Реализация —
`affixWeight()` в `itemgen.ts`. Текущий контент (в `affixes.json`):

- стихийный урон (`flaming/frozen/shocking/venomous`) и мана (`arcane`) → `weapon.magical ×2`;
- физ-урон (`cruel/merciless`) → `weapon.physical ×1.6`, крит (`deadly`) → `weapon.physical ×1.4`.

Эффект (замер): физ-аффиксы ~20% на магическом оружии против ~69% на физическом. Правится в
редакторе: у аффикса поле `tagWeights` — добавь строку «тег (выпадашка) + множитель». Можно
завести и тематические теги (напр. «огненная база»), если добавить их базам.
