# Dungeon Master

Браузерный dungeon-crawler в духе Diablo 2 (top-down экшн-RPG). Монорепо на npm workspaces.

> Для навигации по коду и архитектуре начните с [CLAUDE.md](CLAUDE.md) и [docs/](docs/).

## Пакеты
- `packages/shared` — типы, формулы, события, реестр конфигов (общий фундамент).
- `packages/client` — Phaser 3 + Vite (игра).
- `packages/server` — Node + Express (сейвы/аккаунты; SQLite — с M14).
- `packages/editor` — HTML-редактор конфигов.

## Быстрый старт (Windows, двойной клик)
- **`start-game.bat`** — поднимает клиент (:5173), сервер (:3001) и редактор (:5174) в
  отдельных окнах с логами, ждёт готовности и открывает вкладки браузера. При первом
  запуске сам делает `npm install`.
- **`start-editor.bat`** — только редактор конфигов (:5174).

Логика — на PowerShell (`scripts/*.ps1`), окна серверов остаются открытыми; закрыть окно =
остановить сервер. Нужен установленный Node.js LTS (проект на Vite/Express).

## Быстрый старт (вручную)
```bash
npm install
npm run dev       # клиент (5173) + сервер (3001)
npm run editor    # редактор конфигов (5174)
npm test          # юнит-тесты формул/событий/конфига
```

Открыть игру: http://localhost:5173

## Управление
- **WASD** — движение, **ЛКМ** — базовая атака (по типу оружия), **ПКМ / 1–4** — активные скиллы.
- **E** — взаимодействие (NPC, портал, лестница), **I** — инвентарь, **K** — скиллы,
  **C** — персонаж, **J** — журнал квестов.

## Статус
Вертикальный срез M1–M16 реализован (см. [docs/MODULE_MAP.md](docs/MODULE_MAP.md)): классы,
процедурные подземелья, бой с оружием/скиллами, лут-генератор, инвентарь/экипировка, две
ветки прокачки (атрибуты + два дерева скиллов), город (магазин/кузница/мастер/доска квестов),
квесты (основные + случайные), смерть с потерей лута, сейвы (localStorage + сервер `node:sqlite`
с анти-читом), HTML-редактор конфигов с live-apply. 37 юнит-тестов, все пакеты проходят `tsc`.
