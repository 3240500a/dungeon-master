# @dm/editor — HTML-редактор

Автор-форма конфигов из zod-схем + инструменты + документация. Правки применяются в игру live (через сервер `/api/config` + BroadcastChannel). Запуск: `npm run editor` (Vite, порт 5174). Прод: собранный клиент и редактор на одном origin.

## Верхние секции (таб-бар в шапке, `main.ts` → `section`, персист в localStorage)

- **🎮 Игра** — левый nav (свёртываемые группы конфигов) + инструменты-вкладки (🧪 Симулятор, 🗺 Забеги v2, 🎲 Генератор предметов, 👹 Генератор мобов, 🧮 Калькулятор, 🔥 Свипы). Правый — авто-форма страницы (`renderPage`) или инструмент. Мостик `editorNav` (напр. Симулятор → Калькулятор).
- **🧍 3D-эдитор** — поз-редактор во всю панель через `iframe` (`pose-editor.html` клиента; dev кросс-ориджин 5173, prod относительный). Авторинг поз/анимаций/походки/поворотов/внешности/3D-моделей; сохранения — общий серверный `pose_store` (`/api/pose`).
- **📖 Документация** (`docs.ts`) — вкладки-описания механик. Контент — markdown в `packages/editor/docs/*.md`, втянут через Vite `import.meta.glob('../docs/*.md', {query:'?raw', eager:true})`; рендер — `marked`. Имя файла `NN-slug.md` задаёт порядок; заголовок = первый `# H1`. Deep-link на конфиг: ссылка `[текст](config:<key>)` или `[текст](config:balance/<группа>)` → после рендера навешивается клик, переводящий в секцию «Игра» на нужную страницу (`gotoConfig` в `main.ts`).

### Как добавить/править доку

Положить/поменять `.md` в `packages/editor/docs/` (dev — перезагрузить страницу, glob eager). Формат: **Что это → Как работает → Ключевые рычаги → Где в конфиге** (с `config:`-ссылками). Стиль markdown — `.doc-body` в `index.html`.

## Ключевые файлы

- `main.ts` — оболочка (таб-бар) + `renderGame` (nav+страница) + `gotoConfig`; состояние `section`/`view`/`current`.
- `docs.ts` — секция документации (glob + marked + deep-link). `docs/*.md` — контент.
- `form.ts` — авто-формы из zod; `sim.ts`/`calc.ts`/`sweep.ts`/`itemGen.ts`/`monsterGen.ts`/`runGen.ts` — инструменты; `passiveGraph.ts`/`skillGraph.ts` — граф-редакторы; `gameHarness.ts` — мост к реальным панелям игры.
