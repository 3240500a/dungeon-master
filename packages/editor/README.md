# @dm/editor — HTML-редактор конфигов

Отдельная Vite-страница для правки всех игровых конфигов. Формы авто-генерируются из
zod-схем `@dm/shared`, поэтому новое поле схемы сразу появляется в редакторе.

## Возможности
- **Страницы по механикам:** Баланс, Классы, Предметы, Аффиксы, Уники, Монстры,
  Подземелья, Скиллы (активные/пассивные), Квесты (основные/случайные) — навигация слева.
- **Полный CRUD** для конфигов-массивов: список записей + форма; «Новая», «Дублировать»,
  «Удалить». Узлы деревьев скиллов редактируются как записи (поля `requires`, `x`, `y` —
  связи/позиции).
- **Авто-формы** из схем: `src/form.ts` рекурсивно строит контролы под тип поля
  (object/array/tuple/record/enum/number/string/boolean).
- **Валидация** при «Применить»/импорте — сломанный конфиг не пройдёт.
- **Live-apply в игру:** «Применить» пишет оверрайд в `localStorage` (`dm:configOverride`)
  и шлёт `BroadcastChannel('dm-config')`; клиент применяет через `ConfigRegistry.reload`.
- **Экспорт/импорт** JSON по конфигу; «Сбросить» — к значениям по умолчанию.

## Запуск
```bash
npm run editor   # http://localhost:5174
```
Игру держите открытой в соседней вкладке — изменения применяются вживую (для уже
сгенерированных объектов — со следующей генерации; при необходимости перезагрузите вкладку).
