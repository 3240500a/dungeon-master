# Бой

## Что это

Разрешение одного удара/попадания: попал ли, заблокировали ли, крит, и сколько урона по типам прошло сквозь броню и резисты. Одна и та же формула (`resolveAttack`) считается на сервере для игрока и монстра — античит и единая правда.

## Как работает

Удар проходит по цепочке (порядок важен — каждый шаг может оборвать):

1. **Попадание.** Шанс = `accuracy / (accuracy + evade)`, зажат в **5%…95%** (даже дохлая точность иногда попадает, идеальная — иногда мажет).
2. **Блок.** Если защитник блокирует — урон **0**. Шанс блока зажат сверху **75%**.
3. **Крит.** С шансом `critChance` урон умножается на `critMultiplier`.
4. **Физмитигация бронёй.** `mitig = armor' / (armor' + 30 + 5·уровень_атакующего)`, где `armor' = armor·(1 − armorPen)`. Броня даёт **убывающую** отдачу и слабеет против высокоуровневых атак. Пробой брони (`armorPen`) режет эффективную броню до расчёта.
5. **Стихийная митигация.** Каждый тип (огонь/холод/молния/яд) режется своим резистом, зажатым **−75%…+75%** (отрицательный = уязвимость → больше урона).
6. **Итог.** Сумма по типам, округление; если в ударе был урон — минимум **1**.

Помимо разрешения удара есть **замах** (windup): удар не мгновенный — есть окно на уклонение/прерывание; и **статусы** (кровотечение, стан, заморозка…), которые накладываются попаданием.

## Ключевые рычаги

- **Кривая брони** — константы `30` и `5·уровень` в митигации: больше → броня слабее; меньше → танки жирнее. Влияет на весь TTK.
- **Каппы** hit 5–95%, block ≤75%, резисты ±75% — определяют «потолки» уклонения/танковости.
- **Точность vs уклонение** — соотношение `accuracy/evade` у классов и монстров задаёт, кто по кому попадает.
- **Крит** (`critChance`/`critMultiplier`) — дисперсия урона и вес крит-билдов.
- **Замах** (доля времени атаки на windup) — окно реакции; больше → бой «читаемее», враги телеграфируют.

## Где в конфиге

- Базовые боевые числа, диапазоны, тайминги замаха, каппы — [Баланс](config:balance) (раздел боя/melee).
- Типы урона и подтипы — [Тип урона](config:damage-kinds), [Физ. подтипы](config:phys-subtypes), [Маг. подтипы](config:magic-subtypes).
- Как оружие раскладывает урон по статам — [Веса оружия](config:weapon-weights).
- Классы брони (сколько брони даёт слот) — [Классы брони](config:armor-classes).
- Статусы/дебаффы (сила, длительность, стаки) — [Состояния](config:debuffs).

> Проверять баланс боя удобно инструментами вкладки **Игра**: 🧪 Симулятор (реальный TTK), 🔥 Свипы (хитмап ударов-до-смерти), 🧮 Калькулятор (сборка билда).
