# Бой

Разрешение одного удара: попал ли, блок, крит, урон сквозь броню и резисты, и какие статусы наложились. Одна функция (`resolveAttack`) считается на **сервере** для игрока и монстра — античит и единая правда. Ниже — весь конвейер с формулами и примерами. Числа в примерах — иллюстративные; тюнящиеся значения помечены и ведут в конфиг.

## Конвейер удара (порядок строгий)

1. **Попадание** — промах → удар кончился.
2. **Блок** — заблокировали → урон **0** (полное гашение, как в D2).
3. **Крит** — умножает урон.
4. **Снижение** — физика бронёй, стихии резистами.
5. **Итог** — сумма по типам, округление, минимум 1.
6. **После удара** — наложение статусов, вампиризм, проки, стан/отброс.

---

## 1. Попадание

```
hitChance = clamp( accuracy / (accuracy + max(1, evade)),  0.05 … 0.95 )
```

Всегда есть 5% промазать и 5% попасть — крайние случаи не гарантированы.

**Пример.** Меткость 130 против уклонения 45:
`130 / (130 + 45) = 130/175 = 0.743` → **74%** попасть.
Против уклонения 300: `130/430 = 0.302` → **30%**.

Меткость/уклонение — дериватив-статы (см. [Классы, атрибуты, прогрессия]); базовые числа и вклад атрибутов — [Баланс](config:balance) и [Классы](config:classes).

> Кровотечение на атакующем режет его меткость (см. статусы): удар считается с `accuracy × accuracyMult`.

## 2. Блок

```
если rng < clamp(blockChance, 0 … 0.75):  урон = 0 (блок)
```

Блок гасит удар **полностью**, но крит/статусы при этом не проходят. Потолок блока — **75%**. Источник `blockChance` — щит/дериватив.

**Пример.** Щит даёт `blockChance = 0.30` → в среднем каждый **3-й** удар в ноль.

## 3. Крит

```
crit = rng < clamp(critChance, 0 … 1)
mult = crit ? critMultiplier : 1
```

**Пример.** `critChance = 0.15`, `critMultiplier = 1.5` → 15% ударов бьют **×1.5**. Множитель применяется ко всему пакету (и физике, и стихиям) до снижения.

## 4. Снижение урона

### Физика — броня

```
эффБроня = armor × (1 − armorPen)                       // пробой оружия/скилла
митигация = эффБроня / (эффБроня + 30 + 5 × уровень_атакующего)
физУрон = базовый × mult × (1 − митигация)
```

Броня даёт **убывающую** отдачу и **слабеет против высокоуровневых** атак (в знаменателе — уровень АТАКУЮЩЕГО).

**Пример.** Броня цели 80, атакующий уровня 10, без пробоя:
`80 / (80 + 30 + 50) = 80/160 = 0.5` → −**50%** физ. урона.
С пробоем `armorPen = 0.25`: эффБроня `80×0.75 = 60` → `60/(60+80)=0.429` → −**43%** (пробой вернул ~7% урона).

### Стихии — резисты

```
стихУрон[t] = базовый[t] × mult × (1 − clamp(res[t], −0.75 … +0.75))
```

Резист по 4 стихиям (огонь/холод/молния/яд) отдельно, зажат **−75%…+75%**. Отрицательный = уязвимость.

**Пример.** Огненный резист 0.40 → `×(1−0.40)=×0.6` (проходит 60% огня). Уязвимость к холоду −0.30 → `×1.30` (+30% урона холодом). Даже «иммун» упирается в −75% (проходит 25%).

### Итог

```
raw = сумма всех типов
урон = был ли в ударе урон ? max(1, round(raw)) : 0
```

### Полный пример удара

Пакет `{ физ 100, огонь 40 }`, крит ×1.5, броня 80 (митиг 0.5), огн.резист 0.25:

| Тип | Расчёт | Итог |
|---|---|---|
| Физ | 100 × 1.5 × (1−0.5) | 75 |
| Огонь | 40 × 1.5 × (1−0.25) | 45 |
| **Всего** | round(120) | **120** |

## Замах, прерывание, окно уклонения

Удар **не мгновенный** — есть замах (windup):

```
времяЗамаха = времяАтаки × baseWindupFrac (+ доля скилла)     // монстр ещё × windupMult поведения
```

- **Телеграф.** Монстр показывает замах (событие `monster-swing`) — окно среагировать.
- **Окно уклонения (whiff).** Ближний удар монстра засчитывается, только если к концу замаха цель ещё в радиусе `сумма_радиусов + 8` — отошёл → удар вхолостую.
- **Прерывание.** Стан/ошеломление во время замаха сбивает удар, если не сработал `interruptResist` (дериватив-стат). У монстра стан **обнуляет** замах.
- **Размах.** Ширина «коридора» удара по дуге: `range × sin(arc)` — та же формула на сервере (попадание) и клиенте (VFX).

Рычаги: `baseWindupFrac`, `baseRange`, `baseArc`, `attackMoveMult` (замедление в атаке) — [Баланс](config:balance) (бой); `windupMult` — [Поведение ИИ](config:monster-behaviors).

### Уклонение (dodge-рывок, пробел)

**Пробел** — универсальный быстрый рывок: уводит игрока из зоны удара и одновременно **сокращает дистанцию** до цели. Направление = **WASD** (куда бежишь), а стоя без движения — **к прицелу** (курсору). Тот же движок, что у скилл-рывков (`p.dash`): пока рывок активен, обычный ввод игнорируется, игрок мчит с фиксированной скоростью, пока не проедет дистанцию или не упрётся в стену.

```
дистанция = distance,  скорость = speed,  длительность = distance / speed
```

- **Позиционное, без i-frames.** Урон не «пропадает» магией неуязвимости — спасает именно **уход из радиуса** к концу вражеского замаха (то самое whiff-окно выше). Тайминг решает: рванул рано — монстр доведёт до тебя, рванул в конце замаха — удар вхолостую.
- **Расталкивает.** В рывке игрок «тяжёлый» (`weightMult`) — проходит **сквозь монстров, отпихивая** их (можно нырнуть за спину), но не сквозь стены.
- **Гейт кулдауном.** После рывка `cooldownSec` секунд рывок недоступен (анти-спам). Ввод эджевый — засчитывается только кадр нажатия, удержание не сыплет рывками.
- **Отменяет замах.** Рывок сбрасывает текущий замах игрока (выход из лока атаки) — можно разорвать свою анимацию, чтобы увернуться.
- **Стан блокирует.** Под станом/оглушением рывок не запускается.
- **Цена.** По умолчанию бесплатно (только КД). Опционально можно включить расход выносливости `staminaCost` (0 = выкл).

**Пример.** `distance = 150`, `speed = 520` → рывок длится `150 / 520 ≈ 0.29с`, за него игрок пролетает 150px в направлении WASD. КД `1.2с` — примерно раз в 1.5с можно нырнуть.

Рычаги: `dodge.distance`, `dodge.speed`, `dodge.cooldownSec`, `dodge.weightMult`, `dodge.staminaCost` — [Баланс](config:balance) (раздел уклонения). Клиент рисует облачко пыли + «вжух» по событию `dodge`; бывший слот скилла на пробеле перевешен на **Q**.

## Статус-эффекты (8 видов)

Статусы **стаковые** и **временны́е**: каждый прок добавляет стак (до `maxStacks`) и обновляет таймер; истёк — снимается. 4 физических (от **подтипа оружия**) + 4 стихийных (от **типа урона** в ударе).

### Как рождается статус

- **Физический** — по подтипу физ. урона оружия ([Физ. подтипы](config:phys-subtypes)): колющий→Рана, режущий→Кровотечение, рубящий→Увечье, дробящий→Ошеломление. Гаснет, если в ударе не осталось физ. урона (полная конверсия в стихию).
- **Стихийный** — для каждой стихии с ненулевой долей в ударе ([Маг. подтипы](config:magic-subtypes)): огонь→Поджиг, холод→Заморозка, молния→Шок, яд→Отравление.

### Наложение (шанс, сила, длительность)

Базовые шанс/сила/длительность вшиты в статус (`debuffs[kind].weapon` для игрока / `.monster` для мобов). Модификаторы:

- **Игрок → монстр.** Статы статусов атакующего усиливают: глобальный `ailmentPct` (шанс И сила) + per-kind бонусы (`chance/power/dur`). `итог_шанс = базовый × (1 + ailmentPct + перкинд_chance)`.
- **Монстр → игрок.** Броня даёт **poise** ([Классы брони](config:armor-classes)): режет и **шанс**, и **длительность** входящего статуса — `× (1 − poise)`. Тяжёлая броня «терпит» контроль.
- **DoT** (кровотечение/поджиг/отравление): сила = **доля от нанесённого урона этого удара** (`mag + magPerDamage × dmg`), не флэт.

### Таблица статусов

| Статус | От чего | Что делает | Формула эффекта | База (оружие игрока) |
|---|---|---|---|---|
| 🩹 **Рана** | колющий | цель бьёт слабее и медленнее идёт | `outDmg = max(0.2, 1 − стаки×0.06)`; `move −= стаки×0.10` | шанс 20%, до 4 стаков, 3с |
| 🩸 **Кровотечение** | режущий | DoT + режет меткость цели | `DoT/с = стаки × (0.04×урон)`; `acc = max(0.6, 1 − стаки×0.05)` | шанс 25%, до 5, 4с |
| 🪓 **Увечье** | рубящий | цель получает больше урона, хуже реген | `recvDmg = 1 + стаки×0.04`; `hpReg ×0.5` | шанс 50%, до 5, 4с |
| 💫 **Ошеломление** | дробящий | −броня, −скор.атаки, шанс оглушить | `armor = max(0, 1 − стаки×0.05)`; `atkSpd ×0.85`; `станШанс = стаки×0.04` | шанс 60%, до 8, 4с |
| 🔥 **Поджиг** | огонь | огненный DoT | `DoT/с = стаки × (0.10×урон)` | шанс 10%, до 3, 3с |
| ☠ **Отравление** | яд | ядовитый DoT | `DoT/с = стаки × (0.06×урон)` | шанс 10%, до 5, 4с |
| ⚡ **Шок** | молния | цель получает больше урона | `recvDmg += стаки×0.10` | шанс 12%, до 2, 3с |
| ❄ **Заморозка** | холод | замедление + −скор.атаки (+ шанс сковать*) | `move −= стаки×0.25`; `atkSpd = max(0.4, база − 0.25×0.6)` | шанс 15%, 1 стак, 2с |

Все числа (шансы/стаки/длительности/пороги-полы) правятся в [Состояния](config:debuffs). Эффекты складываются: увечье+шок оба множат получаемый урон; рана+заморозка оба замедляют.

\* Шанс «полностью сковать» (`freeze.mag2`) заложен в данные, но пока **не применяется** движком — заморозка сейчас только замедляет и режет скорость атаки.

### Примеры статусов

**DoT (кровотечение).** Удар нанёс 75 урона, `magPerDamage = 0.04` → сила стака `0.04×75 = 3/с`. При 5 стаках: `5 × 3 = 15 урона/с` в течение 4с. Каждый новый прок обновляет силу под последний удар.

**Оглушение от ошеломления.** 💫 копится (до 8 стаков), `mag2 = 0.04` → при 8 стаках **шанс оглушить = 32%** за удар. Плюс дробящее оружие может иметь **прямой** шанс стана (булава, сверх накопленного). Оглушение = стан **1.2с** (или `stunSec` скилла — приоритетнее).

**Стак получаемого урона.** Цель под 💫? нет — под 🪓×5 и ⚡×2: `recvDmg = 1 + 5×0.04 + 2×0.10 = 1.40` → **+40%** ко всему входящему урону.

**Замедление.** 🩹×4 + ❄×1: `move = max(0.25, 1 − 4×0.10 − 1×0.25) = max(0.25, 0.35)` → цель идёт на **35%** скорости.

## Что ещё влияет на удар (интеграция)

- **Вампиризм (leech).** Доля нанесённого урона → HP/мана атакующему (`lifeLeechPct`/`manaLeechPct`, дериватив). Лич-за-кил — плоское HP/мана за убийство (`lifeOnKill`/`manaOnKill`).
- **Аффинити + реактивные мастерства.** Урон по цели домножается: аффинити к фракции × (1 + бонусы «при ударе» — по горящим/оглушённым/фракции). См. [Дерево мастерства](config:mastery-tree).
- **Реактивная защита.** При получении удара мастерства могут снизить входящий урон и **отразить** часть.
- **Проки «при ударе».** Аффиксы с `proc` могут кастовать скилл по шансу на удар (реентранси-гард против рекурсии).
- **Добивание / отброс.** Скилл-сигнатуры: доп. урон по целям с HP<35% (`lowHpBonusPct`), отброс с шансом (масштаб по весу цели — тяжёлого толкает слабее).

## Где в конфиге

- Боевые базы, каппы, замах/дальность/дуга, скорости, `attackMoveMult` — [Баланс](config:balance) (бой).
- Типы/подтипы урона и их статусы — [Тип урона](config:damage-kinds), [Физ. подтипы](config:phys-subtypes), [Маг. подтипы](config:magic-subtypes).
- Все 8 статусов (шанс/стаки/сила/длительность/пороги) — [Состояния](config:debuffs).
- Раскладка урона оружия по статам — [Веса оружия](config:weapon-weights). Броня и poise по слоту — [Классы брони](config:armor-classes).
- Меткость/уклонение/крит/резисты как дериватив — [Классы](config:classes) + [Баланс](config:balance).

> Проверять бой на реальном движке: 🧪 Симулятор (TTK), 🔥 Свипы (хитмап ударов-до-смерти), 🧮 Калькулятор (сборка билда) — вкладка **Игра**.
