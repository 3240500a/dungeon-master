# Город и экономика

Хаб между забегами: тратишь золото и добычу — покупаешь зелья/снаряжение, куёшь, сбрасываешь очки, хранишь в сундуке, берёшь квесты. Экономика (золото, цены, кузница, сброс) **авторитетна на сервере** (клиент шлёт действие → сервер применяет → возвращает `saveUpdate`).

## Цены

```
оценка   = round( (15 + itemLevel × 4 + аффиксов × 12) × priceMult(редкость) )
покупка  = оценка
продажа  = max(1, floor(оценка × 0.4))                 // 40% от оценки
```

`priceMult` ([Редкости](config:rarities)): normal ×1, magic ×1.6, rare ×2.4, unique ×4.

**Пример.** Редкий предмет ilvl 30 с 4 аффиксами: оценка `(15 + 120 + 48) × 2.4 = round(183×2.4) = 439` золота; продажа `floor(439×0.4) = 175`.

## Кузница

- **Улучшение** (`forgeUpgrade`) — плоские базовые статы **+20% (мин +1)**, добавляет префикс «★». Цена `balance.forgePrices.upgradeTier`.
- **Реролл аффиксов** (`forgeReroll`) — заново катит столько же аффиксов из пула по редкости предмета. Цена `balance.forgePrices.rerollAffix`.

**Пример.** Меч 30–50 урона → улучшение → `round(30×1.2)=36` … `round(50×1.2)=60` → «★ Меч».

## Мастер прокачки (сброс очков)

- **Сброс мастерства**: комиссия = `вложенное_золото × passiveRespecCostPct`, возвращает **очки мастерства** (не золото).
- **Сброс скилов**: комиссия `skillRespecFee` (за вложенное очко), возвращает очки скилла.

Комиссия растёт с прокачкой (доля вложенного) — чтобы поздняя игра с миллионами не сбрасывала за копейки.

## Лавки, сундук, квесты

- **Лавка зелий / кузница-магазин** — расходники и снаряжение (сток обновляется, `regenShop`).
- **Пояс** — расходники под рукой (ёмкость = `beltSlots` пояса; см. [Инвентарь и экипировка]).
- **Сундук** — общее хранилище между забегами/персонажами.
- **Квесты** — основные ([Квесты: основные](config:quests.main)) и случайные ([Квесты: случайные](config:quests.random)), серверные; награда — золото/опыт/лут.
- **Золото** капает с килов (`goldMult` сложности, `round(rng(1, 5+level×2) × goldMult)`) + продажа.

## Ключевые рычаги

- **Формула цены** (`15 + ilvl×4 + аффиксы×12`, priceMult) + **продажа 40%** — темп «фарм → апгрейд».
- **forgePrices** (upgrade/reroll) — цена крафта.
- **passiveRespecCostPct / skillRespecFee** — цена экспериментов с билдом.
- **Обновление стока** магазина — доступность снаряжения.
- **Награды квестов** + **goldMult** — альтернативный и общий приток золота.

## Где в конфиге

- Цены крафта, приток золота, размеры инвентаря, respec-доли — [Баланс](config:balance).
- Множитель цены по редкости — [Редкости](config:rarities). Что продаётся — [Предметы](config:items.base).
- Множитель золота по режиму — [Сложности](config:difficulties).
- Квесты — [Квесты: основные](config:quests.main), [Квесты: случайные](config:quests.random).
