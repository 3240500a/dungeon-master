# Сложность, тиры глубины, вызов

Масштаб опасности и награды. Три рычага накладываются: **сложность** (режим), **глубина этажа** (как далеко зашёл) и **вызов** (производный «уровень угрозы» на этаже, показывается в HUD).

## Вызов (challenge)

```
эффУровень   = уровень + бонус_гира + бонус_пассивов
стартВызов   = offsetMode=='percent' ? эффУровень × (1 + offset) : эффУровень + offset   (мин 1)
вызовНаЭтаже = round( стартВызов + (этаж − 1) × floorStep )                              (мин 1)
```

Вызов считается от **эффективного** уровня (не только уровня персонажа — гир и пассивы поднимают его), стартовый сдвиг задаёт сложность, и растёт с глубиной этажа (`floorStep`).

**Пример.** ЭффУровень 20:
- Сложная (`offset +5` flat, `floorStep 1.5`): старт **25**, этаж 5 → `25 + 4×1.5 = 31`.
- Лёгкая (`offset −0.1` percent, `floorStep 1`): старт `20×0.9 = 18`, этаж 5 → `18 + 4×1 = 22`.

Вызов виден в HUD («этаж N · сложность · вызов ур.K») — ориентир, когда пора отступать.

## Множители сложности

Каждый режим ([Сложности](config:difficulties)) даёт (пример — Средняя = базовая):

| Поле | Что делает |
|---|---|
| `offsetMode` / `offset` | старт вызова (percent-доля или flat-сдвиг от эффУровня) |
| `floorStep` | насколько вызов растёт за этаж |
| `goldMult` | множитель золота с килов |
| `ilvlBonus` | `+` к уровню предмета дропа (`dropIlvl = level + ilvlBonus`) |
| `magicFind` | `dropBias` при ролле редкости (см. [Лут и предметы]) |
| `unlockFloor` | режим открыт, если на предыдущем дошёл до этого этажа |

Дефолты: Лёгкая `gold 0.9 / mf 0.9 / ilvl −1`, Средняя `1/1/0`, Сложная `gold 1.25 / floorStep 1.5 / …` — риск↔награда.

## Глубина и тиры

- **Уровень монстра** = `глубина + 1`; глубже → злее и дороже дроп.
- **Тиры глубины** ([Тиры глубины](config:depth-tiers)) — границы, где скачком меняется пул/сила контента.
- Итоговые статы монстра = база на глубину × множители сложности; награда (золото/ilvl/magic find) = база × множители.

## Разблокировка режимов

Режим с `unlockFloor > 0` требует достичь этого этажа на **предыдущем** режиме (прогресс по сложностям персиста в сейве). Так более жёсткие сложности открываются за успех на лёгких.

## Ключевые рычаги

- **offset / offsetMode / floorStep** — стартовый и растущий «уровень угрозы».
- **goldMult / ilvlBonus / magicFind** — риск↔награда режима.
- **Границы тиров глубины** — где скачком меняется контент/сила.
- **unlockFloor** — гейт прогрессии режимов.

## Где в конфиге

- Режимы и их множители — [Сложности](config:difficulties).
- Тиры глубины (границы/пул) — [Тиры глубины](config:depth-tiers).
- Базовые кривые уровня/наград, `effectiveLevel` (бонусы гира/пассивов) — [Баланс](config:balance).

> Как режим/глубина двигают TTK и награду — «🧪 Симулятор» и «🔥 Свипы» на вкладке **Игра**.
