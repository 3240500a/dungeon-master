# Классы, атрибуты, прогрессия

Кем играешь и как растёшь. Класс задаёт старт и уклон; 4 атрибута (STR/DEX/INT/VIT) деривят весь боевой стат-блок; уровни дают очки на атрибуты и деревья. Дериватив-статы считаются одной функцией и для игрока (в бою/калькуляторе).

## Атрибуты → статы (деривация)

Порядок: **база + вклад атрибутов + прибавка за уровень**, затем модификаторы гира/пассивов/тоглов, затем капы.

```
maxHp      = hpBase + VIT × hpPerVitality + (уровень−1) × hpPerLevel
maxMana    = manaBase + INT × manaPerInt + VIT × manaPerVit + (уровень−1) × manaPerLevel
maxStamina = staminaBase + STR × staminaPerStr + DEX × staminaPerDex + (уровень−1) × staminaPerLevel
меткость   = 20 + DEX × 2 + (уровень−1) × accuracyPerLevel
уклонение  = 10 + DEX × 1.5
castSpeed  = 1 + INT × 0.008                         // 100 INT ≈ ×1.8
moveSpeed  = moveSpeedBase(120) × moveSpeedMult
hpRegen    = hpRegenBase + VIT × hpRegenPerVit
manaRegen  = manaRegenBase + INT × manaRegenPerInt + VIT × manaRegenPerVit
staminaRegen = staminaRegenBase + STR × staminaRegenPerStr + DEX × staminaRegenPerDex
```

Первый уровень — **без** прибавки за уровень (`lvlGain = уровень − 1`). Крит-база 5% (×1.5), броня/резисты/блок с гира.

**Что качает каждый атрибут (по умолчанию):**

| Атрибут | Даёт |
|---|---|
| **STR** (Сила) | выносливость, её реген, урон физ-оружия (ведущий), броня |
| **DEX** (Ловкость) | меткость, уклонение, скор.атаки, крит, урон finesse-оружия |
| **INT** (Интеллект) | мана + её реген, скорость каста, урон стихийного оружия |
| **VIT** (Стойкость) | HP + её реген, часть маны |

Точные коэффициенты (`hpPerVitality`, `manaPerIntelligence`, `accuracyPerLevel`, …) — [Баланс](config:balance) (прогрессия/мощь).

### Капы (после всех модификаторов)

- Крит **0…100%**, блок **0…75%**, резисты **−75%…+75%**, `interruptResist` **0…100%**.

**Пример.** DEX 40, уровень 10: меткость `20 + 40×2 + 9×accuracyPerLevel`, уклонение `10 + 40×1.5 = 70`. INT 60 → castSpeed `1 + 60×0.008 = 1.48`.

## Класс

Класс ([Классы](config:classes)) задаёт:

- **Стартовые атрибуты** и базовые статы (уклон: «родной» атрибут/оружие).
- **Гейты входов** в древо скилов (какая ветка открыта классу).
- **Дефолтную внешность** для 3D (`baseAppearance` — вид без экипа).

Дериватив (скорость каста от INT и т.п.) — общий с расчётом статов; класс лишь задаёт стартовые числа и модификаторы.

## XP, уровень, очки

```
уровень = levelForXp(суммарный_XP, balance.xpTable)     // кумулятивная таблица
порог текущего уровня = xpTable[lvl], следующего = xpTable[lvl+1]
кап уровня = xpTable.length − 1
```

За уровень выдаются **очки**: атрибутов (в STR/DEX/INT/VIT), скилла (в древо скилов), мастерства (в дерево мастерства). Часть узлов имеет **гейт уровня**.

**Пример.** XP-таблица (начало) `[0, 0, 97, 424, 1098, 2273, 4062, …]`: чтобы стать 3-м уровнем нужно 97 XP, 4-м — 424. Разрыв растёт → поздние уровни дольше. Кап (по конфигу) ~90.

## Ключевые рычаги

- **Стартовые атрибуты/статы класса** — идентичность и стартовая мощь.
- **Коэффициенты деривации** (сколько даёт 1 очко STR/DEX/INT/VIT) — вес атрибута, «что стакать».
- **Кривая xpTable** — темп прокачки на глубине; кап уровня.
- **Очков за уровень** (атр/скилл/мастерство) — скорость раскрытия билда.
- **Гейты входов/уровня** — порядок раскрытия и характер класса.
- **Капы** (крит/блок/резист) — потолки защиты/крита.

## Где в конфиге

- Классы (старт, уклон, гейты, `baseAppearance`) — [Классы](config:classes).
- Коэффициенты деривации, xpTable, кап, очки за уровень, реген, `moveSpeedMult`/`attackMoveMult` — [Баланс](config:balance).
- Куда тратятся очки — [Древо скилов](config:skill-tree), [Дерево мастерства](config:mastery-tree).
