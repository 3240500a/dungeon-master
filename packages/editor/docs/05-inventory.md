# Инвентарь и экипировка

Хранение и надевание предметов: сетка инвентаря, слоты экипировки, пояс под расходники, сундук, требования. Статы надетого суммируются в деривацию персонажа (см. [Классы, атрибуты, прогрессия]).

## Слоты экипировки

- **Оружие (main)** + **офф-рука (off)**: щит / второе оружие / фокус. Пара образует ключ `main+off` (влияет на позы удара и щит-оверлей).
- **Шлем, броня, перчатки, сапоги, пояс, бижутерия.**
- Каждый предмет несёт `baseStats` (масштаб тиром) + `affixes` → всё складывается в дериватив (урон/броня/резисты/скорость/крит/…).

## Сетка инвентаря и пояс

- **Сетка** — предметы занимают клетки (`gridW × gridH`, как в D2), кладутся drag-and-drop; пупсик-паперкукла показывает надетое.
- **Пояс** — быстрые ячейки под расходники (зелья). Ёмкость = `beltSlots` надетого пояса; без пояса пояс недоступен.
- **Сундук** — общее хранилище в городе (между забегами/персонажами по правилам сейва).

## Требования и poise

- **Требования** — чтобы надеть, нужны атрибуты/уровень не ниже планки предмета. Планка задаётся при генерации (масштаб тиром + кап `maxTotalRequirement`, см. [Лут и предметы]) — дроп не бывает «мёртвым».
- **Poise (стойкость брони)** — броня по слоту даёт poise: входящий статус-контроль режется `× (1 − poise)` и по **шансу**, и по **длительности**. Тяжёлая броня «терпит» оглушение/кровотечение/заморозку (см. [Бой], наложение статусов). Значения — [Классы брони](config:armor-classes).

## 3D-вид экипировки

У предмета — поле `modelId` (3D-модель по слоту): оружие/щит — общий GLB (хват per-персонаж), броня/шлем — submesh-вариант атласа класса. Пустой слот → базовый вид класса (`baseAppearance`). Привязка мешей к слотам — на вкладке **3D-эдитор**.

## Ключевые рычаги

- **Размеры предметов** (`gridW`/`gridH`) — плотность инвентаря.
- **Ёмкость пояса** (`beltSlots` поясов) — сколько расходников под рукой.
- **Классы брони** — броня и **poise** по слоту (танковость + сопротивление контролю).
- **maxTotalRequirement** — доля дропа, реально надеваемого.
- **Вес оружия main/off** — раскладка урона и что уходит в офф-руку.

## Где в конфиге

- Базы предметов (слот/размер/kind/baseStats/requirements) — [Предметы](config:items.base).
- Броня и poise по слоту/типу — [Классы брони](config:armor-classes).
- Раскладка урона оружия по статам — [Веса оружия](config:weapon-weights).
- Размеры инвентаря, планка требований — [Баланс](config:balance).
