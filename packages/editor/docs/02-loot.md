# Лут и предметы

Генерация случайного предмета: база → тир → редкость → аффиксы → имя → требования. Один конвейер (`generateItem`/`buildItem`) читают игра, дроп, магазин, квесты и песочница «🎲 Генератор предметов». Ниже — каждый шаг с формулами и примерами (числа тюнятся, ссылки ведут в конфиг).

## Конвейер

1. **Уровень дропа** `ilvl = max(minTier базы, round(уровень_вызова))` — глубина+сложность (см. [Сложность и тиры]).
2. **Редкость** — каскад по порогам, `dropBias` (magic find) повышает шанс редких.
3. **База** — по `baseId` (магазин/квест) или взвешенно по категориям × `dropWeight`.
4. **Тир** — высший доступный по `ilvl`, зажатый диапазоном базы `[minTier, maxTier]`.
5. **Аффиксы** — по редкости, ilvl и типу предмета.
6. **Имя** — тир-префикс / magic-слова / «говорящее» rare / титул уника.
7. **Требования** — масштаб тиром + пропорциональный кап.

## Редкость

```
r = rng() / dropBias
каскад «редчайшее-первым» по threshold: r < threshold ? эта редкость
```

Пороги ([Редкости](config:rarities)): unique **0.02**, rare **0.12**, magic **0.40**, normal **1.0**.

**Пример (dropBias = 1.0):**

| Редкость | Шанс | Аффиксов | Цена ×  |
|---|---|---|---|
| Уникальный | 2% | фикс. набор | ×4 |
| Редкий | 10% | 3–5 (до 3 преф + 3 суф) | ×2.4 |
| Магический | 28% | 1–2 (до 1+1) | ×1.6 |
| Обычный | 60% | 0 | ×1 |

**Magic find.** `dropBias = 1.5` делит `r` → `r<t ⟺ rng<1.5t`: unique ~3%, rare ~15%, magic ~42%, normal ~40%. `dropBias` = magic find сложности (см. [Сложности](config:difficulties)) × уклон биома.

## Тир (качество базы)

Лестница ([Предметы: тиры](config:item-tiers)) — высший тир с `minItemLevel ≤ ilvl`, но зажат `[minTier, maxTier]` базы:

| Тир | с ilvl | статы × | треб. × |
|---|---|---|---|
| Убогий | 1 | 1.0 | 1.0 |
| Старый | 8 | 1.3 | 1.5 |
| Крепкий | 18 | 1.8 | 2.2 |
| Отличный | 30 | 2.5 | 3.2 |
| Мастерский | 45 | 3.4 | 4.6 |
| Элитный | 62 | 4.6 | 6.8 |
| Мифический | 80 | 6.0 | 10.0 |

Тиром масштабируются **только урон и броня** базы (`statMult`), прочее (скор.атаки/блок) — флэт.

**Пример.** Меч 10–20 урона, дроп ilvl 30, диапазон базы t0…t6 → тир **Отличный** (×2.5) → **25–50 урона**. А «Ржавый нож» с `maxTier = Крепкий` даже на ilvl 80 остаётся **Крепким** (×1.8) — дешёвая база не станет мифической. Симметрично `minTier` не даёт «мифрилу» упасть в Убогий.

> ⚠ Тир **Убогий** — это КАЧЕСТВО вещи (плохо сделана), а не состояние. Слово «сломано» в игре
> занято отдельным флагом трофея с трупа: сломанное нельзя надеть, пока не починишь.
> Подробнее — вкладка **Материалы, разбор и крафт**.

## Аффиксы

```
пул = аффиксы, где enabled И подходит типу (appliesTo/exclude)
              И есть тир на этом ilvl И проходит гейт magic/rare
число = rng(minAffixes … maxAffixes), делится преф/суф в пределах maxPrefix/maxSuffix
выбор = взвешенный (weight × tagWeights), из одной group — не больше одного
```

- **Фильтр по типу** (`appliesTo`/`exclude`) по токенам: вид (`weapon`/`armor`/…), слот, грань оружия (`weapon.melee`, `weapon.physical`). Пустой `appliesTo` = подходит всем.
- **Тег-веса** (PoE2-стиль): `weight × ∏ tagWeights` совпавших тегов — магическое оружие чаще катает стихии, физическое — физ. свойства.
- **Ролл значения:** берётся **лучший тир аффикса с `ilvl ≤ ilvl предмета`**, значение `rng.float(min, max)`. Атрибуты — вверх до целого, прочее — до сотых.

**Пример.** Редкий предмет ilvl 40 → `rng(3,5)` аффиксов, до 3 преф + 3 суф, каждый из своей группы; у аффикса «+огонь» с тирами на ilvl 1/15/35 берётся тир-35, значение из его `[min,max]`.

## Имя

- **Обычный** — тир-префикс + база, склонён по роду: «**Крепкий** меч», «**Крепкая** секира».
- **Магический** — слово-префикс + база + слово-суффикс: «Жгучий меч ярости».
- **Редкий** — «говорящее» ([Имена rare](config:rare-names)): **основа** по типу урона (стихия из add-урона / физика / стихия из резиста) + **эпитет** по главному вторичному свойству (вампиризм/крит/защита/…). Напр. «Искра жажды» = молния + вампиризм.
- **Уникальный** — база + фикс. титул из [Уники](config:uniques).

## Требования

```
скалир = требования базы × reqMult тира
если Σ скалир > кап:  все атрибуты × (кап / Σ)     // пропорционально
```

Кап — `balance.maxTotalRequirement` (дефолт 180). Не даёт дропу стать «мёртвым» (недостижимым).

**Пример.** База: сила 60 + ловк 40 (Σ100). Тир reqMult ×3 → Σ300 > кап 180 → все ×(180/300)=0.6 → **сила 108, ловк 72** (Σ180).

**Округление ужатых долей — наибольшим остатком:** пол каждой доли, недостающие до ⌊кап⌋ очки — крупнейшим дробным частям
(ничья — большему атрибуту). Сумма ужатых требований = кап ровно, не больше. Пример: 14:26 на t6 при капе 190 → доли 66.5 и
123.5 → **сила 66, ловк 124** (Σ190; округление по атрибуту давало 67 + 124 = 191). Неужатые — обычное округление, пока
сумма после него не выше ⌊кап⌋; иначе — тем же наибольшим остатком. Пример (правка ступени до reqMult ×2.5): 37:39 → 92.5 + 97.5 =
190 ровно на капе → **сила 92, ловк 98** (обычное округление давало 93 + 98 = 191).

## Уники

При редкости unique берётся случайный из [Уники](config:uniques): его база + `fixedAffixes` (не роллятся) + титул. Если уник выпал, а пул пуст/выключен — дроп «падает» в rare. Тир/требования уника считаются как у обычного дропа.

## Выбор базы и категории

Без явного `baseId` база берётся **взвешенно**: `categoryWeights` (из `balance.loot`) × per-item `dropWeight`. Выключенные базы (`enabled:false`) из случайного дропа исключены (явный `baseId` — можно). Расходники (колбы) **не** роллят редкость/аффиксы/тир — всегда обычные.

## Ключевые рычаги

- **Пороги редкости** + `dropBias`/`magicFind` — как часто видишь magic/rare/unique.
- **Тир-лестница** (`statMult`/`reqMult`, `minItemLevel`) — разрыв «мусор ↔ топ» и гейт по глубине.
- **Пул аффиксов** (тиры `[min,max]`, `weight`, `tagWeights`, `appliesTo`, `group`) — чем интересны предметы и что на что катается.
- **Слоты редкости** (`minAffixes`/`maxAffixes`/`maxPrefix`/`maxSuffix`) — «плотность» свойств.
- **maxTotalRequirement** — доля дропа, реально надеваемого.
- **categoryWeights** + `dropWeight` + `dropBias` биома — что чаще падает.

## Где в конфиге

- Базы (union weapon/armor/shield/consumable/jewelry) — [Предметы](config:items.base).
- Тиры — [Предметы: тиры](config:item-tiers). Редкости (пороги/слоты/цена) — [Редкости](config:rarities).
- Аффиксы (тиры/веса/appliesTo/group/proc) — [Аффиксы](config:affixes). Уники — [Уники](config:uniques).
- Имена рара — [Имена rare](config:rare-names).
- Шанс дропа, categoryWeights, кап требований, ilvl-бонус — [Баланс](config:balance) + [Сложности](config:difficulties).

> ⚠ Шанс дропа вещи — всего **10 %**, и это не скупость: основной поток наград — материалы с надетого гира монстра.
> Прежде чем крутить `dropChance`, прочти вкладку **Материалы, разбор и крафт**: эти два числа живут в паре.

> Катать по реальному генератору (с seed) — «🎲 Генератор предметов» на вкладке **Игра**.
