# Скилы и мастерства

Две независимые системы прокачки: **древо скилов** (активные + пассивные узлы, за очки скилла) и **дерево мастерства** (%-пассивы, за золото + очки мастерства). Ниже — движок активок, ресурсы, ранги и цены с формулами.

## Древо скилов

Единое РАДИАЛЬНОЕ дерево. Узел прокачивается по рангам; активка при касте тратит ресурс и уходит в кулдаун.

### Цена и доступность

```
скилл-узел: cost.type = 'points',  списывает cost.amount ОЧКОВ СКИЛЛА
доступность: ранг>0 ИЛИ вход ИЛИ есть прокачанный смежный узел (по рёбрам)
```

Сброс скилов — за золото (`skillRespecFee` за вложенное очко), возвращает очки. Очки скилла капают за уровень (см. [Классы, атрибуты, прогрессия]).

### Ранг усиливает

```
урон    × abilityRankMult(ранг) = 1 + 0.12 × (ранг − 1)      // +12%/ранг
кулдаун × max(0.35, 1 − 0.03 × (ранг − 1))                   // −3%/ранг, пол 35%
```

**Пример.** Ранг 5: урон ×1.48, кулдаун ×0.88. Ранг 10: урон **×2.08**, кулдаун ×0.73 (пол −65% достигается к ~рангу 22).

### Типы активок (`active.category`)

| Тип | Что делает | Ключевые поля |
|---|---|---|
| **attack** | удар оружием: ближний → ВСЕМ в дуге; дальний/маг → веер из снарядов | `count`, `spread`, `damageMult` |
| **cast** | заклинание с временем каста | `castTimeSec`, `convertPct`, `addElementPct` |
| **curse** | накладывает дебафф/проклятие на цель/область | `ailment` |
| **aura / stance** | тумблер: резервирует долю ресурса, даёт баффы | `reservePct`, `toggleGroup`, `buffMods` |
| **dash / leap** | рывок/прыжок | `dashSpeed` (× ранг) |

**Атака (веер).** Дальнобой/маг пускает `n = max(1, count)` снарядов, разложенных по `spread` (углу): смещение i-го = `−spread/2 + spread·i/(n−1)`. Урон каждой = `damageMult`. Ближняя атака бьёт всех в дуге удара (см. [Бой]).

**Каст.** Пакет урона = состав урона **оружия** × `damageMult` × ранг, затем:
- `addElementPct` — добавить долю базового урона как стихию сверху;
- `convertPct` — слить долю всего урона в стихию (0..1) — режим «всё в стихию».

Время каста:
```
времяКаста = castTimeSec / max(0.2, castSpeed)
castSpeed  = 1 + Интеллект × 0.008          // 100 INT ≈ ×1.8
```
**Пример.** `castTimeSec = 1.0`, INT 50 (castSpeed 1.4) → **0.71с**; INT 100 (×1.8) → **0.56с**.

### Ресурсы

```
canSpend: (resource=='stamina' ? стамина : мана) ≥ manaCost
```

- **Мана** — касты; **Выносливость** — боевые активки (`resource` узла).
- ⭐ **ВСТАВКА ПЛАТИТ СВОИМ РЕСУРСОМ.** У вставки есть `costPool`: `carrier` (надбавка растёт в пуле
  носителя, как у физических вставок) или свой пул. Стихия, магические статусы, новы и печати
  помечены `mana` — их надбавка НЕ удорожает выносливость, а списывается маной отдельной второй
  ценой (`ResolvedActive.extraCost`). Огонь в мече — магия, и платит за него мана.
  ```
  вторая цена = цена носителя × (costMult − 1) × (1 + perRank.cost·(ранг−1)) × курс
  курс = balance.inserts.manaPerStamina (и staminaPerMana в обратную сторону)
  ```
  Надбавка считается от ИСХОДНОЙ цены носителя — иначе результат зависел бы от порядка вставок в гнёздах.
- ⭐ **НЕ ХВАТИЛО МАНЫ — ВСТАВКА ГАСНЕТ, А НЕ СКИЛ.** Способность пересобирается без вставок этого пула
  (`resolveActive(..., { omitPools })`): удар проходит физическим, стихия не применяется и не оплачивается.
  Замах помнит это решение (`windup.omit`), чтобы удар не прилетел со стихией, за которую не заплатили.
  Своего пула не хватило — как раньше: скил просто не срабатывает.
- **Прок вставки платит САМ** (`proc.ability.manaCost`): «Волна холода» и «Дуговой разряд» — настоящие
  новы, и бесплатными на каждом взмахе они быть не должны. Нет маны — прок молчит, носитель бьёт.
- ⚠ **Обратной симметрии нет:** физические вставки остаются `carrier` — иначе у мага они стали бы почти
  бесплатными (выносливость он не тратит), и это был бы не выбор, а лазейка.
- **Реген из статов**: `manaRegen` от INT+VIT, `staminaRegen` от STR+DEX (базы+коэффициенты в [Баланс](config:balance)).
- **Резерв (тоглы/ауры)**: включённый тумблер резервирует долю пула → эффективный максимум ниже:
  ```
  эффМакс = максимум × (1 − Σ reservePct включённых)
  ```
  Нельзя зарезервировать весь пул. `toggleGroup` — взаимоисключающие стойки (включение одной гасит другую из группы).
  **Пример.** Аура `reservePct = 0.35` → доступная мана = 65% максимума.

### Прочее

- **Замах/прерывание** активок — как у атак (см. [Бой]): стан/ошеломление сбивает, если не сработал `interruptResist`.
- **Гарантированный стан скилла** (`stunSec`) приоритетнее случайного от оружия.
- **Аффинити + сет-бонусы** — множители урона по фракции/сборке.
- **Проки** — аффиксы с `proc` кастуют скилл по шансу на удар.

## Дерево мастерства

Плоские %-пассивы (%-урон/статы/статусы). Прокачка стоит **золото + очко мастерства**:

```
цена ранга = round(cost.amount × passiveRankCostMult^ранг)      // геометрия, дефолт ×2
списывает: цена ЗОЛОТА + 1 очко мастерства
доступность: ранг>0 ИЛИ вход дерева ИЛИ смежный прокачанный узел
```

**Пример.** База узла 50 золота, mult ×2: ранги стоят **50 → 100 → 200 → 400…** (3 ранга = 350 золота + 3 очка).

**Сброс мастерства.** Комиссия = `вложенное_золото × passiveRespecCostPct` (растёт с прокачкой, чтобы поздняя игра с миллионами не сбрасывала за копейки); возвращает **очки** (не золото), чистит осиротевшие узлы. Входы дерева доступны всем классам (класс-гейт снят), дальше — по смежности.

## Ключевые рычаги

- **abilityRankMult / abilityCooldown** (0.12 / 0.03 / пол 0.35) — насколько ранг усиливает и ускоряет.
- **castSpeed от INT** (0.008/ед) — темп магии.
- **manaCost / staminaCost, реген** — как часто спамишь активки.
- **reservePct** тоглов/аур — цена «постоянных» баффов.
- **count / spread** атак — веер vs одиночный.
- **convertPct / addElementPct** — гибкость стихийных билдов.
- **cost.amount** узлов + `passiveRankCostMult` + respec-fee — темп раскрытия и цена экспериментов.
