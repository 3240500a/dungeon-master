# Монстры

## Что это

Монстры устроены как игрок: у них атрибуты (STR/DEX/INT/VIT) + экипировка, а боевой стат-блок **деривится** из них теми же правилами. Плюс восприятие (зрение/слух/LoS), профили ИИ по фракциям, и 4 редкости через гир.

## Как работает

### Генерация и статы

- Монстр генерится из базы ([Монстры](config:monsters)) на глубину этажа: атрибуты + уровень масштабируются, сложность добавляет свои множители.
- Стат-блок (HP/урон/точность/броня/резисты) **деривится** из атрибутов+гира по [Деривации](config:monster-derive) — не хардкодится.
- **Гир** монстра ([Монстры: экипировка](config:monster-gear)) катает аффиксы из ОТДЕЛЬНОГО пула [аффиксов шмота](config:monster-item-affixes) (не плеерских), таргетинг по `appliesTo`.

### Редкость (ровно 4, без чемпионов)

`normal → magic → rare → unique`. Редкость = **количество слотов гира** ([Монстры: редкость](config:monster-rarity)): больше слотов → злее. **Unique** = элита + уникальное имя ([Имена уникальных](config:monster-uniques)) + гир на всех слотах. Одна истина — конфиг.

### Восприятие и ИИ

- **Восприятие**: зрение (радиус+угол) + слух + прямая видимость (LoS по сетке). Есть задержка «заметил» (`alertDelay`) и аггро от шума (удар игрока рядом).
- **Профили поведения** по фракциям ([Поведение ИИ](config:monster-behaviors), резолвер `behaviorFor`): преследование с «поводком» (leash), обход стен (патфайндинг-гибрид BFS), FSM (flee / juggernaut / reposition), сигнатуры (блинк-каст у джиннов, взрыв-overload конструктов при смерти).
- **Замах** монстра телеграфируется (`monster-swing`) — окно на уклонение; `windupMult` у тяжёлых делает удар «читаемее».

### Пачки и спавн

Монстры расставляются пачками по типам комнат/этажам ([Пачки монстров](config:packs)); фракция берётся от биома. Труп в 3D коллапсирует физикой и запекается; на сервере мёртвый монстр держится недолго и удаляется (снапшот не растёт).

## Ключевые рычаги

- **Деривация статов** — как атрибуты+гир превращаются в HP/урон/защиту (главный рычаг сложности мобов).
- **Слоты гира по редкости** — насколько magic/rare/unique злее обычного.
- **Пул аффиксов шмота** мобов — какие свойства носят враги.
- **Восприятие** (зрение/слух/LoS/alertDelay) — насколько монстры «зоркие» и агрессивные.
- **Профили ИИ** — характер фракции (наскок, кайт, блинк, тычок-отход).
- **Плотность пачек** и **множители сложности** — общий напор этажа.

## Где в конфиге

- Базы монстров — [Монстры](config:monsters). Деривация — [Монстры: деривация](config:monster-derive).
- Гир — [Монстры: экипировка](config:monster-gear); его аффиксы — [аффиксы шмота](config:monster-item-affixes).
- Редкость — [Монстры: редкость](config:monster-rarity); уник-имена — [Имена уникальных](config:monster-uniques).
- Поведение ИИ — [Поведение ИИ](config:monster-behaviors); подфракции/роли — [Подфракции](config:subfactions), [Роли](config:monster-roles).
- Тиры глубины — [Тиры глубины](config:depth-tiers). Пачки — [Пачки монстров](config:packs).

> Проверить конкретного моба (стат-блок, гир, TTK против билда) — «👹 Генератор мобов» на вкладке **Игра**.
