# Монстры

Монстр устроен как игрок: у него атрибуты (STR/DEX/INT/VIT) + экипировка, а боевой стат-блок **деривится** из них теми же правилами. Плюс восприятие (зрение/слух/LoS), профили ИИ по фракциям и 4 редкости через гир. Ниже — генерация, деривация, гир и ИИ с формулами.

## Генерация и деривация статов

```
уровень = глубина_этажа + 1
атрибут = база × (1 + (уровень − 1) × levelGrowth)      // рост атрибутов, дефолт +10%/ур
```

Из атрибутов+гира деривятся боевые статы ([Монстры: деривация](config:monster-derive), дефолты):

| Стат | Формула | Дефолт-коэф |
|---|---|---|
| HP | `hpBase + VIT × hpPerVit + уровень × hpPerLevel` (+ гир) | 6 / 1.2 / 1 |
| Урон | `урон_оружия × (1 + ведущий_атрибут × dmgPerAttr)` | 0.02 |
| Броня | `STR × armorPerStr` (+ броня гира) | 0.15 |
| Меткость | `accBase + уровень × accPerLevel` | 20 / 3 |
| Уклонение | `evadeBase + DEX × evadePerDex` | 5 / 1.5 |
| Скор. атаки | `DEX × iasPerDex` | 0.001 |
| Крит | `DEX × critPerDex` | 0.0015 |
| Резисты | `уровень × resistPerLevel` | 0.005 |
| XP | `(xpBase + уровень × xpPerLevel) × tierXp` | 12 / 5 |

Ведущий атрибут урона: **STR** для физ. оружия, **INT** для стихийного. `tierXp` домножает опыт по тиру (weak 0.7 / medium 1 / strong 1.8 / boss 4). Сложность добавляет свои множители поверх (см. [Сложность и тиры]).

**Пример (глубина 5 → уровень 6, levelGrowth 0.1):** база STR 10 → `10 × (1 + 5×0.1) = 15`. Меткость `20 + 6×3 = 38`. HP `6 + VIT×1.2 + 6` (+ броня/оружие гира).

## Гир и 4 редкости

Ровно 4 редкости, **без чемпионов**: `normal → magic → rare → unique`. Редкость = **сколько слотов гира катают аффиксы** ([Монстры: редкость](config:monster-rarity)):

```
слотов_с_аффиксами = clamp( minItems + floor((уровень−1) / levelsPerItem),  min … min(max, надетых_слотов) )
```

| Редкость | minItems | maxItems | +1 слот / N уровней |
|---|---|---|---|
| Обычный | 0 | — | — |
| Магический | 1 | 4 | 12 |
| Редкий | 2 | 4 | 16 |
| Уникальный | 4 | 4 | (все слоты) |

**Unique** = элита + уникальное имя ([Имена уникальных](config:monster-uniques)) + гир на всех слотах. **Одна истина — конфиг** (редкость определяется только гиром).

- Гир монстра — [Монстры: экипировка](config:monster-gear); катает аффиксы из **отдельного** пула [аффиксов шмота](config:monster-item-affixes) (не плеерского), таргетинг по `appliesTo`.
- Гир даёт монстру и боевые статы (броня/урон/резисты через деривацию), и 3D-вид (оружие/броня/щит).

**Пример.** Магический моб уровня 25: `1 + floor(24/12) = 3` слота с аффиксами (до 4 надетых).

## Восприятие (зрение / слух / LoS)

- **Зрение** — радиус + угол конуса (`vision`, `visionAngle` монстра) + **прямая видимость** (LoS по сетке — стена рвёт луч). Игрок в конусе и на линии видимости → замечен.
- **Слух** — радиус `hearing`: удар игрока рядом даёт аггро даже без прямой видимости (`hearingMode`: `chase` — сразу в погоню, `investigate` — идёт проверить точку шума).
- **Задержка** — `alertDelaySec`: «заметил» не мгновенно перед первой атакой (окно среагировать/уйти).

## ИИ (FSM по профилям фракций)

Профиль ([Поведение ИИ](config:monster-behaviors), резолвер `behaviorFor`) задаёт характер фракции:

- **Погоня с поводком (leash).** Преследует `leashTimeSec` в радиусе `leashRadius`; потерял/устал → возврат к точке спавна (`home`).
- **Патфайндинг.** Идёт напрямую при LoS; за стеной — BFS-обход (кэш пути с троттлом).
- **Бегство** (`fleeHpPct`) — при HP ниже доли отступает (кайтеры/трусы).
- **Репозиция** (`repositionMode`): `strafe` — тычок-отход, `blink` — телепорт-уклонение (джинны, с КД), `none` — прёт напролом.
- **Джаггернаут** (`windupMult > 1`) — тяжёлый «читаемый» замах (телеграф длиннее).
- **Сигнатуры** — блинк-каст у магов, взрыв-`overload` конструктов при смерти.

**Замах монстра** телеграфируется событием `monster-swing`; окно уклонения — если к концу замаха отошёл за `радиус+8`, удар вхолостую (см. [Бой]).

## Пачки и спавн

Монстры расставляются **пачками** по типам комнат/этажам ([Пачки монстров](config:packs)); **фракция берётся от биома** этажа. Спавнятся на входе на этаж. Мёртвый монстр в 3D коллапсирует физикой и запекается; на сервере труп держится коротко и удаляется (снапшот не растёт).

⚠ **Монстр в пуле биома — ещё не спавн.** Пачка берёт монстров ПО РОЛИ: роль, которой нет ни в одной пачке, не выходит
никогда. Сейчас в пачках крипты только scout / warrior / thrower — охранник, колдун, шаман, лучник, рыцарь и арбалетчик
лежат в пуле, но не спавнятся. Внутри роли монстр выбирается по весу глубины (кривая тира или `spawnCurve`) × **доле
слота** `spawnShare`. Доля нужна ДВОЙНИКАМ — той же заготовке с другим оружием (копьё, алебарда, жезл, булава, посох,
арбалет; см. «Экономика → кто носит»): двойники и источник делят слот, доли группы в сумме 1, и состав пачки по роли и
тиру не меняется. Обычному монстру поле не нужно (1). Симулятор («Бой», «Этаж», «Прокачка») выбирает монстра тем же
весом (`monsterPicker` в `sim/floor.ts`): раньше он брал поштучно, и двойники раздували свою роль — метателей в «Бое»
было 4/19 вместо прежней 1/13.

## Ключевые рычаги

- **Коэффициенты деривации** (`hpPerVit`/`dmgPerAttr`/`armorPerStr`/…) + `levelGrowth` — главный рычаг сложности мобов на глубине.
- **Слоты гира по редкости** (`minItems`/`levelsPerItem`) — насколько magic/rare/unique злее.
- **Пул аффиксов шмота** — какие свойства носят враги.
- **Восприятие** (`vision`/`visionAngle`/`hearing`/`alertDelaySec`) — «зоркость» и агрессия.
- **Профиль ИИ** (`leash*`/`fleeHpPct`/`repositionMode`/`windupMult`) — характер фракции.
- **Плотность пачек** + множители сложности — напор этажа. `tierXp` — награда опытом по тиру.

## Где в конфиге

- Базы монстров (атрибуты, vision/hearing, тир) — [Монстры](config:monsters). Деривация — [Монстры: деривация](config:monster-derive).
- Гир — [Монстры: экипировка](config:monster-gear); его аффиксы — [аффиксы шмота](config:monster-item-affixes).
- Редкость — [Монстры: редкость](config:monster-rarity); уник-имена — [Имена уникальных](config:monster-uniques).
- Поведение ИИ — [Поведение ИИ](config:monster-behaviors); подфракции/роли — [Подфракции](config:subfactions), [Роли](config:monster-roles).
- Тиры глубины — [Тиры глубины](config:depth-tiers). Пачки — [Пачки монстров](config:packs).
