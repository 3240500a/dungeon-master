# Текстуры: как готовить

Oct 8, 2026 · рекомендации к финальному арту (Unity URP Lit); тестовый набор крипты пока на временной схеме — она описана в конце

## Коротко

- Один **набор текстур** = один материал. Имя набора = имя модели, если у модели один материал: `crypt_fire_pit_01.fbx` ↔ `crypt_fire_pit_01_a.png`, `_n`, `_m`, `_e`. Тогда Unity свяжет всё сама, без таблицы переименований.
- Приставка — **биом**: `crypt_…`. Никаких `dungeon_`.
- **PNG, 8 бит**, квадрат, степень двойки. 16 бит после сжатия в игре ничего не даёт, а исходник становится в 2–3 раза тяжелее.
- Нормали — **OpenGL (Y+)**. Маска — **RGBA**: металл, AO, пусто, гладкость.
- Кладёшь в `Assets/DM/Art/Textures/<биом>/` — материал `Materials/<биом>/<набор>.mat` соберётся сам.

## Роли и каналы

| Суффикс | Что | Формат файла | Как читается в игре |
|---|---|---|---|
| `_a` | цвет (albedo / base color) | RGB, sRGB. Альфа — только если нужна прозрачность или вырез | DXT1 (с альфой — BC7) |
| `_n` | нормали | RGB, **OpenGL (Y+)** — зелёный «вверх» | BC5 |
| `_m` | маска | **RGBA**: R = металл, G = AO, B = не используется (чёрный), A = гладкость | BC7, линейная |
| `_e` | свечение | RGB, sRGB. Чёрное — не светится, цвет = цвет свечения | DXT1 / BC7 |

### Цвет `_a`
- Без запечённого света и теней: свет даёт игра (факелы, свет героя). Мягкий AO в цвет можно, но слабый — AO живёт в маске.
- Металл в цвете — его настоящий цвет (сталь — светло-серая), а не «тёмный, потому что металл».

### Нормали `_n`
- **OpenGL.** Так ждёт Unity. В Substance Painter при экспорте — «Normal OpenGL»; при запекании в Max — без переворота зелёного.
- Проверено замером на текущем наборе: все карты крипты уже OpenGL. Четыре спорные (fire_pit_01, wall_statue_02, wall_statue_03, wooden_props) стоит глянуть глазами — рельеф «внутрь» вместо «наружу» значит перевёрнутый зелёный.

### Маска `_m` (финальная схема)
- **R — металл:** 0 для камня, дерева, ткани, кожи; 1 для голого металла; ржавчина и краска на металле — 0.
- **G — AO:** белый, если AO нет. Чёрный G = всё чёрное.
- **B** — не используется, чёрный.
- **A — гладкость** = 1 − шероховатость. Белое = блестит (мокрый камень, полированный металл), чёрное = матовое.
- Альфа обязана быть **в файле** (PNG-32). Без альфы гладкость станет 1 по всей поверхности — пластик.
- Substance Painter: пресет экспорта **«Unity HDRP (Metallic Standard)»** даёт маску ровно в этой раскладке (MaskMap: R металл, G AO, B detail, A гладкость) — переименовать в `_m`.

### Свечение `_e`
- Только там, где светится само (угли, руны, глаза). Яркость крутится в материале (Emission в инспекторе .mat), не в текстуре.
- Свет на окружение даёт не свечение, а точка `light_*` в модели (см. ниже).

## Размеры

Камера сверху, примерно в 10 м от пола, клетка = 1 м. Ориентир — **плотность текселей одинаковая по всему набору**, примерно 512 px на метр для пола и стен.

| Что | Готовить в | Пример |
|---|---|---|
| Пол (один набор на все варианты плиток) | 2048 | `crypt_floor_01` на 9 плиток |
| Стены | 2048 | `crypt_wall_01` на 3 стены и арку |
| Колонны, крупные пропсы (очаг 2×2, статуя) | 2048 | `crypt_fire_pit_01` |
| Мелкие пропсы — **общим атласом** | 2048 на группу | `crypt_wooden_props_01` на 7 деревянных пропсов |
| Отдельный мелкий проп без атласа | 1024 | факел |
| Персонажи, монстры | 2048 | |
| Оружие | 1024 | |

- Исходник больше 2048 не нужен: в игре сейчас потолок 2048. Меньший размер под пресет графики (1024 на «Низких» и т.п.) Unity получает, срезая верхние мипы, — отдельные файлы не нужны.
- Атлас дешевле по вызовам отрисовки и по числу бандлов, но любая правка атласа скачивается игроками целиком (≈8–15 МБ). Тайлы и крупное — своими наборами, мелочь — атласом.

## Что должно быть в FBX

- Слот материала ссылается на `_a` своего набора — по этой ссылке Unity сама свяжет слот с материалом. Пути не важны, важно имя файла.
- Имена узлов — без пробелов и `[ ] . : /`.
- **Стены и колонны:** два узла — `<имя>_lo` (цоколь 0…0.67 м, не гаснет у камеры) и `<имя>_hi` (выше, гаснет).
- **Свет:** пустышка `light_01` (`light_*`) там, где источник. Можно поставить и в Unity — в префабе модели.
- **Коллизия (по желанию):** меш `collider*`. Нет его — коллайдер берётся по габариту модели.
- Единицы — сантиметры Max (Unity переводит сама), клетка = 1 м. Пивот: плитка пола — центр снизу; стена — плоскость лица в 0, тело назад на 0.375 м; проп — центр на полу; настенный проп — на плоскости стены.

## Где что лежит

| Файл | Куда |
|---|---|
| FBX тайлов биома | `Assets/DM/Art/Env/<биом>/<кит>/` — несколько FBX в папке = кит (префаб `<кит>.prefab` соберётся сам) |
| FBX пропса биома | `Assets/DM/Art/Env/<биом>/<ключ>/<ключ>.fbx` |
| Текстуры | `Assets/DM/Art/Textures/<биом>/` |
| Материалы | собираются в `Assets/DM/Art/Materials/<биом>/` — правь в инспекторе, правило их не перезапишет |

## ⚠ Временная схема тестового набора крипты (08.10)

Текущие `_m` крипты — серые, без альфы (R=G=B). Пока они идут в слот металла с гладкостью из яркости («Alpha From Grayscale», как делалось руками) — металл и гладкость равны яркости, AO нет. Это не по договору выше; при финальных текстурах маски переделываются на RGBA, временное правило импорта убирается. Размеры (2048 у всех) пересматриваются вместе с пресетами графики.
