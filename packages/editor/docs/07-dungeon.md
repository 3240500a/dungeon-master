# Генерация подземелий

## Что это

Процедурная сборка этажа: геометрия комнат/коридоров по алгоритму биома, врезка префабов, расстановка дверей/рычагов, декора, монстров и лестницы вниз — с гарантией проходимости.

## Как работает

- **Алгоритм по биому**: `rooms` (комнаты+коридоры), `bsp` (бинарное разбиение), `cellular` (пещеры), `maze` (лабиринт). У каждого свои параметры плотности/размера.
- **Проходы**: 3-проходная генерация — геометрия → обогащение (двери/ключи/рычаги, декор, сундуки) → пачки монстров. Инвариант: этаж **всегда проходим** (валидатор), спавн ≠ лестница, есть пол.
- **Двери ↔ рычаги**: закрытая дверь всегда имеет достижимый рычаг; проверяется на сотнях сидов (юнит-тест-инвариант).
- **Префабы комнат** ([Комнаты](config:room-prefabs)) — врезаются в этаж (камеры/залы с сундуками), не ломая проходимость.
- **Туман войны** — раскрытие по прямой видимости (LoS) на клиенте.
- **Фракция монстров** берётся от биома; пачки ставятся по типам комнат/этажам (см. [Забеги] / [Монстры]).

## Ключевые рычаги

- **Выбор алгоритма на биом** и его параметры — характер этажа (тесные комнаты vs пещеры vs лабиринт).
- **Плотность/размер комнат**, длина коридоров.
- **Частота дверей/рычагов**, сундуков, декора (обогащение).
- **Пул префабов** и вероятность врезки.
- **Число этажей** и что где спавнится (через шаблоны забега).

## Где в конфиге

- Этажи/типы этажей — [Этажи](config:floors).
- Префабы комнат — [Комнаты (префабы)](config:room-prefabs).
- Биомы (алгоритм, уклон дропа, фракция) — [Биомы](config:biomes).
- Пачки монстров по комнатам/этажам — [Пачки монстров](config:packs).
- Структура забега (какие узлы-этажи) — [Шаблоны забега](config:run-templates).
