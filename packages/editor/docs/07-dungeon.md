# Генерация подземелий

Процедурная сборка этажа: геометрия по алгоритму биома → обогащение (двери/рычаги, декор, сундуки) → пачки монстров, с **гарантией проходимости** (валидатор на сотнях сидов).

## Алгоритмы (по биому)

| Алгоритм | Что даёт |
|---|---|
| `rooms` | комнаты + коридоры |
| `bsp` | бинарное разбиение пространства |
| `cellular` | пещеры (клеточный автомат) |
| `maze` | лабиринт (`maze.width` = толщина коридоров, шаг решётки = width+1) |
| `prefab` | целый этаж из префаба-рисунка |

Форма комнаты (`carveRoomShaped`): `rect` / `ell` (эллипс) / `blob` / `round` / `hall`. Параметры (плотность/размер/`loops`/`shapes`/`prefabChance`) — в редакторе.

## Связность и проходимость

- **Граф связей** (`connectByNeighborGraph`): граф Габриэля ∪ стено-смежные комнаты → **MST + браид** (добавка петель), каждое ребро проводится один раз (нет дублей-коридоров).
- **Проёмы/коридоры** (`connectRooms`) между связанными комнатами.
- **Старт ↔ выход** разнесены (`farthestPair` / `pickSpawnExit`): спавн и лестница — в дальних точках.
- **Инвариант** (юнит-тест на сотнях сидов): этаж **всегда проходим** (`validate`), спавн ≠ лестница, пол есть.

## Двери, рычаги, туман

- **Двери ↔ рычаги**: у каждой закрытой двери есть **достижимый при закрытых дверях** рычаг; у каждого рычага — своя дверь. Инвариант проверяется генерацией+тестом.
- **Невидимые стены-колонны** (`Cell.Pillar`) блокируют проход и рисуются (в т.ч. форма `hall`).
- **Туман войны** — раскрытие по прямой видимости (LoS) на клиенте.

## Префабы комнат

Префаб ([Комнаты](config:room-prefabs)) — рисунок по клеткам (пустая клетка `' '` пропускается, `trimPrefab` = размер из рисунка), врезается, не ломая проходимость:

- `prefab`-алгоритм = целый этаж;
- `stampRoomPrefab` = вставка в комнату (`rooms`/`bsp`) по `prefabChance`;
- `carvePrefabChambers` = врезка камер в пещеры/лабиринт по `prefabRooms{min,max}` + `reconnectFloor` (слить компоненты пола).

Зоны рисунка (`d`/`m`/`c`/`e`/`x`) → контент (двери/мобы/сундуки/…). Отбор префабов (`selectPrefabs`) по `biomes`/`algorithms` префаба (пусто = во всех).

## Монстры и фракция

- Пачки ставятся по типам комнат/этажам ([Пачки монстров](config:packs)); **фракция — от биома** этажа.
- Спавн только на `Cell.Floor` (в нерегулярных биомах — перевыбор+скан, чтобы не попасть в стену).

## Ключевые рычаги

- **Алгоритм на биом** + параметры (плотность/размер/`loops`/`shapes`) — характер этажа.
- **Частота дверей/рычагов**, сундуков, декора (обогащение).
- **Пул префабов** и `prefabChance`/`prefabRooms` — вероятность врезки.
- **`maze.width`** — толщина коридоров лабиринта.
- **Плотность пачек** — напор.

## Где в конфиге

- Этажи/типы этажей — [Этажи](config:floors). Биомы (алгоритм, уклон дропа, фракция) — [Биомы](config:biomes).
- Префабы комнат — [Комнаты (префабы)](config:room-prefabs).
- Пачки монстров — [Пачки монстров](config:packs). Структура забега — [Шаблоны забега](config:run-templates).
