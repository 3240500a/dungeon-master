# public/ — статические файлы клиента

Файлы отсюда Vite копирует в корень сборки и отдаёт по адресу `/<имя>` (доступны из Phaser по
относительному пути без префикса).

## Фон главного меню
Положи сюда картинку под именем **`menu-bg.png`** (или `.jpg` — тогда поправь имя в
`src/scenes/MainMenuScene.ts`). Она автоматически станет фоном меню, растянутым «cover» под экран.
Рекомендуемый размер — 1920×1080 (16:9), но подгонится под любой.
