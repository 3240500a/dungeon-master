# Модуль: quests (клиент — чистый вью)

Квесты: основная цепочка + случайные с доски. **Авторитет — сервер** (анти-чит): вся логика
и награды в shared `economy/questLogic.ts`, трекинг — в серверном `Room` по событиям сессии.
Клиент только отображает и шлёт команды.

- **Логика (shared, чистая):** `economy/questLogic.ts` — `acceptQuest(save, def, quota?)`,
  `turnInQuest(reg, save, id)`, `trackObjective(save, 'kill'|'collect-item', target)`,
  `trackFloor(save, depth)`, `ensureMainQuest(reg, save)`, `generateBoard(reg, rng)`,
  `questFromTemplate(tpl, rng, uid)`, `questXp(level, xpTable, permille)`. Мутируют `save`.
- **Трекинг (сервер `Room`):** из событий сессии — `monster-died.by` (kill по `def.id`),
  `item-picked` (collect-item по `item.baseId`), `enterDungeon` (reach-floor по глубине,
  общий прогресс пати). Изменения шлются владельцу как `saveUpdate` + событие `quest`.
  ⚠ R3-10: reach-floor — только НОВЫЙ вход в узел; продолжение припаркованного забега (`resumeRun`) возвращает
  на пройденный узел и не засчитывается (иначе «достичь этажа 2–4» закрывалось спуском из города мгновенно).
  R4-04: и узел, где кто-то из участников забега уже был. ⚠ R4-26: collect-item не считает вещь, выброшенную игроком
  и поднятую снова (`item-picked.thrown` — у дропа есть владелец): иначе «собрать N» закрывала одна вещь.
- **Основная цепочка:** `ensureMainQuest` при входе игрока/в город выдаёт `quests.main[0]`;
  при сдаче квеста с `next` следующий принимается автоматически (в `turnInQuest`).
- **Случайные:** доска `Room.questBoard` из `quests.random`, шлётся клиенту кадром
  `questBoard` (→ `app.questBoard`); «Взять» = команда `acceptQuest`.
  ⚠ R3-10: КВОТА — одно задание шаблона за срок доски (`balance.townRestockSec`) на героя, в сейве
  (`QuestProgress.acceptedAt`): доска — сток героя-хозяина комнаты, и доски альтов больше не множат квесты ни в
  новой комнате, ни на другой ноде. Отказ — «Такое задание уже взято — доска обновится позже».
  ⚠ R4-33: срок меряется между ПОКОЛЕНИЯМИ досок (`QuestProgress.boardAt` ← `stock.at`), а не от принятия:
  взял на 9-й минуте доски — на 10-й она обновилась, и то же задание с новой доски берётся сразу. Прогресс до правки
  (только `acceptedAt`) меряется временем принятия. ⚠ R5-19: с доски, пережившей свой срок (стоял в городе дольше
  `townRestockSec`), не берут — сервер катает новую, шлёт её кадром `questBoard` и отвечает «Доска обновилась — выбери
  задание заново»: иначе принятое писало поколением «сейчас», и следующая честная доска отказывала в том же шаблоне.
  ⚠ R5-20: журнал доски не растёт без конца — сданное с доски убирается из `save.quests`/`activeQuestDefs` сразу
  (`pruneBoardQuests`; при входе в комнату — и у старых сейвов), поколение переезжает в `save.boardQuota[шаблон]`, и
  квота смотрит туда тоже. От шаблона в журнале одно задание: новое поколение вытесняет невыполненное прежнее (копить
  «достичь этажа» на один спуск нельзя), выполненное, но не сданное, держит место — «Сначала сдай «…»».
- **Награды при сдаче:** золото/опыт-доля (через shared `gainXp`)/очки скиллов/предмет —
  считает `turnInQuest`, клиент шлёт `turnInQuest`, сервер отвечает `saveUpdate`.
- **Хранение:** `save.quests` (прогресс) + `save.activeQuestDefs` (резолвнутые определения).
- **Конфиг:** `quests.main`, `quests.random`, `items.base` (награды-предметы).
- **Протокол:** C→S команды `acceptQuest`/`turnInQuest`; S→C кадр `questBoard` + событие
  сессии `quest{kind:'accepted'|'completed'|'turned-in'}` (→ строка в личный лог).
- **UI:** `questLogPanel.ts` (клавиша J) — ЧИСТЫЙ ВЬЮ: активные/к сдаче из `save`, доска из
  `app.questBoard`; кнопки шлют команды. NPC «Доска квестов» в городе.
- **Тесты:** `shared/src/economy/questLogic.test.ts` (приём/трек/сдача+повтор/этаж/доска/квота R3-10, журнал R5-20),
  `server/src/net/room.run.test.ts` (R3-10: продолжение забега и доски альтов; R5-06: «Уничтожить N» от статуса — тому,
  кто повесил; R5-20: чистка журнала при входе).
- **Начатое задание доски (R6-13):** «Взять» при начатом задании того же шаблона (`questRival` — счётчик > 0) спрашивает и шлёт `acceptQuest {replace: true}` только после «да» (`takeQuest`); без согласия сервер начатое не трогает и отказывает с его именем. Не начатое заменяется молча, как в R5-20. Тесты — `takeQuest.test.ts`, `questLogic.test.ts`, `server/net/room.r6core.test.ts`.
- **Вопрос вне города — в игре (R7-12):** журнал (J) открывается и в подземелье, доска там жива, `acceptQuest` сервер исполняет везде — поэтому вне города `takeQuest` спрашивает плашкой `askInGame` (`ui/kit.ts askHere`), а не `window.confirm` (страница вставала, через 10 тиков сервер останавливал героя, монстры били — правило R1-14). После «да» перепроверка: задание ещё на доске и прежнее — то самое (иначе «Задание не взято: …» в лог); снятый игрой вопрос (`dismissAsk`) — «нет». В городе — `window.confirm`, как было. Тест — `takeQuest.test.ts`.
