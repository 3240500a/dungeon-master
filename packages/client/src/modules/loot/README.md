# Модуль: loot

Дроп случайных предметов и золота, подбор с земли.

- **Контракт:** `LootController` (`lootController.ts`) — слушает `monster:died`, катит
  золото и (с шансом) предмет, роняет `DroppedItem`. Подбор: **клик** по предмету (в любой
  момент) ИЛИ **авто** при проходе рядом для редкостей из `balance.autoPickup`.
  `dropToGround(item)` — выбросить из инвентаря (с задержкой перед авто-подбором).
  Создаётся в базовой `GameScene` — работает и в городе, и в подземелье. `destroy()`.
- **Сущность:** `DroppedItem` (`droppedItem.ts`) — спрайт+подпись, цвет по редкости
  (`RARITY_COLOR`/`RARITY_HEX`).
- **Конфиг:** `items.base`, `affixes`, `uniques`, `dungeons` (dropBias темы).
- **События:** слушает `monster:died`; шлёт `item:dropped`, `item:picked`, `gold:changed`.
- **Формулы:** `generateItem`, `rollRarity` (`@dm/shared/formulas/itemgen`).
- **Единый конвейер:** все предметы (старт/квест/магазин/дроп/уник) собираются одним
  `buildItem` в `itemgen.ts`; `itemFromBase`/`generateItem` — тонкие обёртки. Тир берётся
  по уровню предмета ВЕЗДЕ (старт/награды тоже) — исключений нет. Единая база — `items.base`.
- **Вилка базы (как в D2):** урон оружия (мин и макс порознь, ±15 %) и броня (±20 %) катаются вокруг
  числа тира (`balance.loot.baseRoll`). На вещи — доля броска `Item.baseRoll`; нет поля = середина
  вилки = прежние числа. Бросок тянется ПОСЛЕДНИМ из rng генератора. Все вызовы `generateItem` передают
  `baseRoll` из конфига, иначе правка вилки в редакторе не дошла бы до игры.
- **Трофей и сырьё с тела** (`shared/formulas/trophy.ts`, `salvage.ts`): падает база игрока по надетому, сырьё — по
  `monster-gear.salvageTo`; с F2 оружие даёт и семьи верхних гнёзд ковки (`trim`/`stave`/`focus`, ступень 1). ⚠ Класс
  оружия падает, только если его носитель СПАВНИТСЯ: пачки берут монстров по роли, поэтому копьё, алебарду, жезл,
  булаву, посох и арбалет носят двойники спавнящихся монстров (`monsters[].spawnShare`, docs/CRAFT_WEAPONS.md §20).
- **Тесты:** генерация предметов — `shared/formulas.test.ts`; вилка базы — `shared/formulas/craft.test.ts`; «каждый класс
  оружия падает с монстра, который реально спавнится» — `shared/formulas/trophy.test.ts`; двойники — `monsterTwins.test.ts`.
- **Использование:** `scenes/DungeonScene.ts`.
- **Добыча и стена (R6-26):** бросок награды ложится только в видимости трупа (стены, закрытые двери, высокий декор), подбор (клик, [E], автоподбор), сундук и рычаг — только в видимости героя. **Выключенное сырьё (R6-22)** не падает и с тел (`salvageFromMonster` + `knownMaterial`). Тесты — `session.test.ts` (R6-26), `economy/materialsLive.test.ts` (R6-22).
