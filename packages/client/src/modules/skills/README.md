# Модуль: skills (панель древа скилов, клавиша K)

Окно ЕДИНОГО древа скилов — **радиальный холст-граф** (как дерево мастерства, но узлы-квадраты).
Из центра ветви расходятся во все стороны: **слева боевые** (выносливость), **справа магия** (мана),
**низ — броня**, **верх — классовая** ветка. Видны универсальные ветки + сигнатурная ветка своего
класса. Внизу окна — панель биндов действий.

- **Файлы:** `skillsPanel.ts` (окно: холст + сборка + бинды снизу), `skillTreeView.ts` (SVG-граф: квадраты
  по стороне/стихии, вход — золотой контур, пан/зум, тултип, клик = вложить очко), `socketsView.ts`
  (гнёзда и вставки), `skillIcon.ts` (цвет стихии/иконка). Аллокация/статы — в `../skills-active`
  (`activeTreeFor`/`allocateActive`).
- **Рендер узла:** актив крупнее и с цветом стихии, пассив — тон стороны (`sideColor`), нотабль крупнее;
  вложено — золото + золотые рёбра, доступно — подсветка стороны, закрыто — тёмное; вход — золотой контур.
- **Прокачка:** клик по доступному узлу → `sendCmd({cmd:'allocSkill', nodeId})` (сервер авторитетен,
  `townActions.allocActive`). Первое вложение активного узла уходит в хотбар.
- **Сброс за золото:** кнопка в шапке → `sendCmd({cmd:'respecSkills', maxGold: fee})`. Возвращает все очки скиллов,
  комиссия `balance.skillRespecCostPerPoint`×вложенные очки; бинды сброшенных скиллов очищаются. R5-15: `maxGold` —
  комиссия, названная в вопросе: дороже сервер не возьмёт (его конфиг мог уйти вперёд).
  ⚠ R4-05: сервер кастует ТОЛЬКО выученное (`castSkill`: ранг в `save.skills` > 0) — бинд тут ни при чём, кадр
  ввода несёт `cast` как есть; включённые до сброса ауры/стойки и баффы гаснут на следующем тике (`dropUnlearned`).
  Гнёзда (`save.sockets`) сбрасываются вместе с деревом — иначе вставки повисли бы на сброшенных узлах.
- **СБОРКА СКИЛА (`socketsView.ts`):** под холстом — выученные активки, у каждой гнёзда (число даёт
  `socketsOpen` по рангу, пороги `balance.skillSocketRanks`). Клик по гнезду → список вставок; в списке
  ТОЛЬКО возможное (открыта деревом, подходит по `fits` и оружию, тип не занят другим гнездом) — чтобы
  игрок не тыкал в отказы, но решает всё равно сервер (`socketInsert`/`socketClear`). Итоговые
  стоимость/откат считает `resolveActive` — тот же шов, что у сервера и редактора.
- **Узел-донор:** узел с `effect.grantsInsert` помечен ромбиком в углу и говорит в подсказке, какую
  вставку открывает. Без метки вставки в дереве не найти — они не отличались бы от обычных пассивок.
- **HUD:** полоса выносливости рядом с маной (`scenes/UIScene.ts`); резерв стоек — приглушённая зона.
- **Конфиг:** `skill-tree`, `skill-inserts`, `skill-insert-types`. **Хранение:** `save.skills`,
  `save.sockets`, `save.hotbar`, `save.unspentSkillPoints`.
- **Тесты:** `skills.test.ts`.
- **Откат баффа (R6-15):** бафф держит свой `cooldown` (`skillCd`), как прочие активки; каст шлёт `swing` без замаха и лока — слот заливается откатом. Раньше повтор в кадр истечения держал бафф 100 % времени.
- **Цена узла (R6-17):** узел древа — ровно 1 очко за ранг (схема `skill-tree`): сброс возвращает очко за ранг.
