# Модуль: movement

Вид игрока и направление взгляда к курсору. **Движение и коллизии — не здесь**, их
считает авторитетная `GameSession` (см. модуль combat / `sessionController.ts`).

- **Контракт:** класс `Player` (`player.ts`) — чистый ВИД (спрайт-`Image` + указатель).
  `update(pointer, camera)` задаёт только `facing` (угол к курсору в мировых координатах) и
  рисует «нос»-указатель; `setPos(x, y)` ставит позицию спрайта; `x`/`y` — геттеры.
- **Движение:** WASD читает драйвер `SessionController` и передаёт как `input.move` в
  `GameSession.tick`; сессия двигает игрока (`moveWithCollision` по сетке) и отдаёт `p.pos`,
  из которого драйвер ставит спрайт. Скорость/замедление (`moveSpeed`, дебаффы) — внутри сессии.
- **Использование:** базовая сцена `scenes/GameScene.ts` создаёт `Player` + драйвер в
  `setupWorld()` (и в городе, и в подземелье), камера следует за спрайтом.
- **События:** нет. Боевые действия (ЛКМ/скиллы) добавляет модуль combat, читая `facing`.
